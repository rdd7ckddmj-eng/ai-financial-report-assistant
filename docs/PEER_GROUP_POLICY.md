# 同行组准入与比较边界

## 1. 为什么“同一年”还不够

共同财务年度只解决时间口径问题，不能证明两家公司具有相近的商业模式、资本需求
或会计结构。白酒、锂离子电池和新能源汽车整车即使都采用 2024 年年报，其收入规模、
利润率、现金转换和负债结构也不能直接合成为优劣排名。

## 2. 两层行业标签

系统把行业信息分成两层：

- **年报披露行业**：保存公司年报中的原始表述、报告标题、官方链接和 PDF 页码；
- **研究同行组**：用于程序筛选的较窄标签，是本项目的研究规则，不冒充监管机构的
  官方估值分类。

行业目录与财务目录必须具有完全相同的公司代码、交易所和公司名称。目录缺项、身份
不一致、链接不是受信任的官方 PDF、页码无效或证据等级不是 A 时，页面拒绝载入。

## 3. 同行组候选的最低条件

只有同时满足以下条件，页面才显示“同行组候选”：

1. 至少两家已核验公司具有相同研究同行组标签；
2. 所有公司存在同一完整财务年度；
3. 数据来自普通非金融企业的已核验合并报表字段；
4. 年报披露行业、研究标签和页码证据均已保存。

“候选”仍不等于完全可比。进入估值或排序以前，还需要人工检查主营业务分部、地区
和产品结构、收入确认、一次性损益、会计政策、重述以及资本结构。

## 4. 当前覆盖

当前目录包括五家公司、三个研究同行组：

- 贵州茅台、五粮液、泸州老窖：白酒制造；
- 宁德时代：动力与储能锂离子电池；
- 比亚迪：新能源汽车整车（多元化业务）。

白酒制造已有三家完整年报核验公司，选择其中至少两家时，页面可以显示
“同行组候选”。宁德时代和比亚迪所在组仍各只有一家。默认五家公司一起展示时
仍属于三组跨行业比较，不会为了生成排名而把不同业务强行归类。

## 5. 估值功能的额外门槛

在加入市盈率、市销率或企业价值倍数以前，还必须统一市场数据时点和口径，并处理亏损、
停牌、异常交易、股本变化、净现金或净负债以及报告期后事项。达到这些条件以前，产品
不输出目标价、买入/卖出/持有建议或综合投资分数。
