# 证据增量 Agent 规格

## 用户问题

普通公司页面每次都展示一批公告，但不会告诉用户“自上次研究后发生了什么”。
证据增量 Agent 把重复检索变成连续研究：以当前浏览器保存的上次成功核验时间
为起点，重新检查官方公告，并形成可下载的变化简报。

## 输入与状态

- 输入：已核验的上市公司身份、官方公告元数据、本机上次核验时间；
- 本机状态：最多五家公司，只保存公开公司身份与 ISO 核验时间；
- 不保存：姓名、联系方式、公告正文、年报 PDF、投资观点或用户持仓；
- 不需要登录系统、云数据库或付费 AI API。

## 确定性规则

1. 没有基准时核验包含当天在内的最近30天；
2. 有基准时从基准日期开始核验，最长365天；
3. 只接受巨潮资讯、上交所、深交所和北交所官方域名；
4. 按发布日期、标题和原文链接去重；
5. 将原公告类别合并为财务与业绩、经营事项、资本运作、治理与风险、其他；
6. 基准日期之后的记录标为“新增”；基准日期当天的记录标为“同日待复核”；
7. 页面和简报最多保留最近100条，完整核验数量单独披露。

## 为什么保留“同日待复核”

当前公开公告元数据能稳定取得日期，但不能稳定取得精确发布时间。如果直接把
基准当天所有公告认定为新增，会制造假阳性；如果全部排除，又可能漏掉保存基准
后发布的公告。因此系统保守地重新展示并标注不确定性，由用户打开官方原文复核。

## 输出

- 公告总数、高关注公告数和主题分布；
- 每条公告的变化状态、官方类别、关注程度和官方原文链接；
- 可离线保存的中文 HTML 证据变化简报；
- 明确的数据窗口、截断说明与非投资建议边界。

## 产品边界

本 Agent 是研究更新工具，不是新闻情绪模型、股价预测模型或自动交易系统。
“关注程度”只决定阅读优先级，不表示利好、利空或买卖建议。公开源失败时必须
显示失败，不使用新闻摘要、旧样例或 AI 猜测填补。
