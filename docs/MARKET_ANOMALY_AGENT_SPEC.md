# 市场异动研究 Agent 产品规格

## 1. 定位

市场异动研究 Agent 用于把分散的价格、成交量、普通换手率和官方公告，
整理为一条可追溯的研究路径。它回答的是“哪一天值得进一步复盘、当时有
哪些官方信息”，不回答“下一步会涨还是会跌”。

## 2. 与其他页面的分工

- **K线与市场表现：** 展示完整图表和常规历史统计。
- **市场异动研究 Agent：** 按固定规则筛选候选日期，并连接官方证据。
- **Historical Lens：** 冻结到用户选择的历史日期，完成严格的时点复盘，
  再由用户主动揭示后来表现。

## 3. 确定性信号

最新交易日和历史候选日期均由 Python 计算，不交给大语言模型判断：

1. **涨停候选：** 日涨幅达到对应板块和风险警示规则的参考阈值；
2. **成交量异动：** 当日成交量达到此前20个交易日成交量中位数的2倍；
3. **普通换手率高位：** 当日普通换手率达到此前最多250个有效交易日的
   90%历史分位。

所有滚动基准和历史分位都排除目标交易日自身及未来数据。历史分位至少
需要20个此前有效交易日。

## 4. Agent 综合状态

- 两项或三项触发：显示“复合异动候选”；
- 一项触发：显示对应的单一异动线索；
- 没有触发：显示“未发现强异动”；
- 三项均缺少证据：拒绝生成异动判断。

综合状态只决定研究优先级，不表示利好、利空或买卖方向。

## 5. 官方证据链

用户选择一个候选日期后，系统只检查该日期及此前六个自然日内已经公开的
官方公告：

- 保留公告日期、类别、证据等级和原始链接；
- 排除候选日期之后才公开的公告；
- 显示公告与候选日期相隔几天；
- 明确说明时间接近不等于公告导致价格或成交量变化。

## 6. 历史相似异动

用户选择一个异动日期后，系统可在最近 250 个交易日扫描得到的更早候选
中寻找规则相似日期。任何日期等于或晚于所选日期都会先被排除，因此本
步骤不会使用未来事件或后来收益。

相似度包含四类可审计维度：

1. 三种异动信号组合的重合程度，权重 40%；
2. 日涨跌幅接近程度，权重 20%；
3. 成交量相对前 20 日中位数倍数的接近程度，权重 20%；
4. 普通换手率历史分位的接近程度，权重 20%。

某个数值缺失时，该维度直接退出比较，剩余权重重新归一化；不得把缺失
值当作 0。至少需要信号组合和一个数值维度，同时总相似度达到 25%，才
能展示为候选。页面最多展示三个结果，并允许将更早日期带入 Historical
Lens；后来表现仍需用户主动揭示。

本模块是确定性历史形态比较，不是机器学习预测，也不生成买卖建议。

## 7. 异动研究报告

用户选择候选日期后，可以下载一份独立的中文 HTML 研究报告。报告只复用
页面已经完成的确定性计算和公告时间隔离结果，不会为了导出再次请求行情
或调用大语言模型。

报告保留：

- 公司身份、研究日期和异动分型；
- 当日价格、成交量、普通换手率及其历史分位；
- 计算口径、行情来源和换手率来源；
- 当时已经公开的官方公告链接；
- 被排除的未来公告数量和非因果说明；
- 最多三个严格早于研究日的相似异动、规则相似度、共同信号和可比维度；
- 每个历史案例对应的 Historical Lens 专属复盘入口，自动带入公司代码和
  历史日期，但不提前展示任何后来收益。

HTML 文件可离线打开，也可用浏览器打印为 PDF。这样不会在 Render 免费
服务器上增加 PDF 生成依赖或长期文件存储压力。

复盘入口只接受六位股票代码、ISO 日期和五年选择范围内的日期。Historical
Lens 首次打开时自动载入，之后刷新或操作组件不会反复覆盖用户的新选择。

## 8. 有效换手率边界

东方财富主行情直接提供普通换手率。若主行情暂时不可用而切换至腾讯备用
行情，系统按需读取新浪财经的当日成交量与流通股本，以“成交量÷流通股本”
补充普通换手率，并按交易日期合并；补充源失败时继续显示“数据不足”，
不会影响价格与成交量功能。

普通换手率可以用于公司自身历史位置比较，但不能冒充有效换手率。有效
换手率需要进一步排除大股东、战略持股等实际上不易交易的股份，并要求
可核验的时点自由流通口径；在该分母尚未接入前，页面必须显示“暂不计算”，
不能用0或普通换手率代替。

## 9. 性能与部署

页面按用户选择的公司临时读取数据，并复用有数量上限的一小时缓存。换手率
补充源只在主行情失败且普通换手率缺失时调用一次。它不在Render免费服务器
上批量下载或永久保存全市场历史资料，避免增加内存压力和外部访问压力。

## 10. 产品边界

本 Agent 是异常筛选和证据整理工具，不预测价格，不认定市场因果关系，
不生成个性化投资建议。
