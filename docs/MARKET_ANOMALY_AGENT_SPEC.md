# 市场异动研究 Agent 产品规格

## 1. 定位

市场异动研究 Agent 用于把分散的价格、成交量、普通换手率和官方公告，
整理为一条可追溯的研究路径。它回答的是“哪一天值得进一步复盘、当时有
哪些官方信息”，不回答“下一步会涨还是会跌”。

## 2. 与其他页面的分工

- **K线与市场表现：** 展示完整图表和常规历史统计。
- **市场异动研究 Agent：** 按固定规则筛选候选日期，并连接官方证据。
- **Historical Lens：** 冻结到用户选择的历史日期，完成严格的时点复盘，
  再由用户主动揭示后来表现。

## 3. 确定性信号

最新交易日和历史候选日期均由 Python 计算，不交给大语言模型判断：

1. **涨停候选：** 日涨幅达到对应板块和风险警示规则的参考阈值；
2. **成交量异动：** 当日成交量达到此前20个交易日成交量中位数的2倍；
3. **普通换手率高位：** 当日普通换手率达到此前最多250个有效交易日的
   90%历史分位。

所有滚动基准和历史分位都排除目标交易日自身及未来数据。历史分位至少
需要20个此前有效交易日。

## 4. Agent 综合状态

- 两项或三项触发：显示“复合异动候选”；
- 一项触发：显示对应的单一异动线索；
- 没有触发：显示“未发现强异动”；
- 三项均缺少证据：拒绝生成异动判断。

综合状态只决定研究优先级，不表示利好、利空或买卖方向。

## 5. 官方证据链

用户选择一个候选日期后，系统只检查该日期及此前六个自然日内已经公开的
官方公告：

- 保留公告日期、类别、证据等级和原始链接；
- 排除候选日期之后才公开的公告；
- 显示公告与候选日期相隔几天；
- 明确说明时间接近不等于公告导致价格或成交量变化。

## 6. 有效换手率边界

东方财富主行情直接提供普通换手率。若主行情暂时不可用而切换至腾讯备用
行情，系统按需读取新浪财经的当日成交量与流通股本，以“成交量÷流通股本”
补充普通换手率，并按交易日期合并；补充源失败时继续显示“数据不足”，
不会影响价格与成交量功能。

普通换手率可以用于公司自身历史位置比较，但不能冒充有效换手率。有效
换手率需要进一步排除大股东、战略持股等实际上不易交易的股份，并要求
可核验的时点自由流通口径；在该分母尚未接入前，页面必须显示“暂不计算”，
不能用0或普通换手率代替。

## 7. 性能与部署

页面按用户选择的公司临时读取数据，并复用有数量上限的一小时缓存。换手率
补充源只在主行情失败且普通换手率缺失时调用一次。它不在Render免费服务器
上批量下载或永久保存全市场历史资料，避免增加内存压力和外部访问压力。

## 8. 产品边界

本 Agent 是异常筛选和证据整理工具，不预测价格，不认定市场因果关系，
不生成个性化投资建议。
