# 有坐标依据的拆行负号连接

本规则针对有完整文字层和表格刻线的**合并利润表税前利润行**。它不修改原PDF、原始页文本或财务金额，只在坐标证据明确时生成解析专用的派生文本及逐项记录。无坐标证据的裸横杠仍可能表示空值，不能据此猜测负号。

## 函数契约

```python
derive_signed_amount_geometry(
    page,
    *,
    report_year=None,
    original_text=None,
    previous_page=None,
)
```

`page`及可选`previous_page`是同一个已打开PyMuPDF文档里的Page对象；前页必须物理连续。调用方负责在现有PDF解析锁和资源预算中执行。函数不打开文件、不下载原件、不运行OCR、不调用模型。`original_text`给定时须逐字等于该页实际文字层；报告年度可由明确的双年度表头推导，调用方提供年度时必须一致。

返回值为：

```text
{
  schema: "pdf-signed-amount-geometry.v1",
  parser_text: 原文或仅连接已证实负号后的派生文本,
  adjustments: [] 或一条可复查记录
}
```

调用方继续保留原始`ExtractedPage.text`。文档SHA和原页文本SHA由提取层绑定；使用派生文本前须通过`pdf_text_derivation`的精确重放校验，不能直接信任任意传入的`parser_text`。

## 必须同时满足的条件

1. 本页或紧邻前页具有独立的“合并利润表”标题，以及“项目、可选附注、本年年度、上年年度”组成的完整表头；年度连续、顺序正确、只有两个金额列。前页上下文一旦切入母公司表、其他报表或未知续表就不沿用，包括带括号章节号、中文无顿号编号、字间空格及“续”标记的独立标题；不把正文中提及表名当作表格标题。
2. 科目严格为“利润总额”，可带中文章节编号及明确亏损总额括注。上一行必须为“减：营业外支出”，下一行必须为“减：所得税费用”，两行都有完整双列金额。
3. 本行有上下横线和全部列边界。当前行列边界与表头一致；文字边框完整位于对应单元格内；同一金额单元格恰好存在一个ASCII负号和一个无符号数字，另一年度单元格恰好有一个完整金额。重复候选、跨列或跨行配对不接受。
4. 负号在数字上方，二者字体高度接近、右端对齐；纵向距离和行高与字体高度相称。相邻年度金额在同一行中央，左右金额列留白一致。仅靠文本相邻不足以通过。
5. 原文中该负号和数字只有一个位于同科目区间内的精确连续片段，PDF词序也连续。只移除该片段中的换行和空白并连接原字符；数字、逗号、小数点和符号都来自原件，不创建新数字、不取绝对值、不按勾稽结果推断符号。

接受的金额词法为普通数字或规范千分位数字，可有0至2位小数；不支持括号碎片、科学计数法、逗号损坏或其他破碎数字。仅ASCII `-`可作为本规则的独立符号；其他横线不猜测。此规则不扩大证券、银行、保险等行业模板范围。

## 调整记录

每条记录包含：

- `kind`、`statement`、`metric`、原始`label`；
- `page_number`、`report_year`、`column_year`；
- `start_offset`/`end_offset`：Python字符串索引，右开区间；
- `original_span`/`replacement_span`：原始精确片段与允许的字符连接；
- `sign_bbox`、`amount_bbox`、`cell_bbox`、`row_bbox`：PDF点坐标 `[x0,y0,x1,y1]`；
- `header_page_number`、`header_years`、`year_column_bounds`；
- `supporting_row_labels`和明确的`reason`。

每页最多返回一处修复；不确定时返回空列表及原文。先用原文字串预筛，再读取几何。单页文本上限100,000字符、词数4,000、绘制路径512、路径元素2,048；标签及原始片段各最多80字符。复杂页超限保持无更正，不提高原有PDF字节、页数或全文字符预算。

## 隆基2025年原件验证

官方原件：[巨潮2026-04-29全文](https://static.cninfo.com.cn/finalpage/2026-04-29/1225251647.PDF)，314页、3,311,470字节，SHA-256为`10233740d54740b89dfd772eecac5f04d8fef639489acd3b18b1a35e81bce2c1`。

物理第125页提供2025/2024年度列；第126页税前利润比较期单元格内原文字符区间`[377,396)`是`-\n10,205,897,803.72`。同单元格内负号与数字右端差约0.06 PDF点，单元格边界为`[459.55,197.19,549.10,227.84]`。本规则派生为`-10,205,897,803.72`，没有更改其他字符。

完整PDF已通过当前生产手工上传流程，状态为`ready_for_human_review`；税前利润减所得税费用、归母利润加少数股东损益、资产负债及现金流勾稽均通过。五项结果与原件核对的原始数值一致。314页原始文本与未启用几何规则时逐页完全相同；仅第126页含一条派生处理记录。人工财务确认数仍为0。

真实PDF回归夹具`longi_2025_signed_geometry_excerpt.pdf`只复制原件125/126两页，未编辑文字或坐标；对应JSON记录原文SHA、摘页SHA及物理页映射。它不代替完整PDF验收。完整回执及原文不变核验位于任务`work/longi-geometry-9/receipt.json`、`manual-snapshot.json`、`extraction-invariance.json`。

测试覆盖真实原件、本年与比较期两种列位置、裸横杠空值、跨列、跨行、孤立符号、重复数字、未知科目、表外符号、边界缺失、年度反转/额外年度、母公司切换、未知相邻科目、错误对齐、资源超限、输入文本错配和消费者重放。未启用几何记录的旧纯文本摘页仍保持隆基失败，因此没有静默改写旧证据或旧回执。

## 生产接入与导出

几何读取作为现有提取器的显式开关，默认关闭；手工年报和按需官方年报入口启用并传入年度。读取仍在现有串行锁内，每份文档最多8处，派生文本也计入原有文字预算；任何执行异常或总预算超限整体失败。

消费层逐条验证文档/原文指纹、偏移、仅连接负号的精确修改、坐标包含关系、所属年度列、符号相对位置及原文邻行标签。它检查元数据内部一致性，不声称重新读取了PDF坐标，也不把外部任意记录当作已认证证据。元数据不一致则阻断标准化金额。

利润检查证据的 `excerpt` 保留原始科目行，包括负号换行；`parser_excerpt` 单独保存解析用派生摘录。页面并排显示处理前后片段和原文物理页链接；快照JSON、HTML及人工复核底稿保留处理记录，底稿保存完整坐标；研究案件保留有限处理摘要，完整坐标仍在原底稿中。五项逐字段人工决定要求保持不变。
