# 成交量与换手率研究模块规格

## 1. 产品目标

该页面回答“交易参与程度是否相对活跃”，不回答“股票接下来是否上涨”。
所有结论由 Python 固定规则生成，不使用大模型猜测数值，也不输出买卖建议。

## 2. 自动数据范围

页面按用户当前选择的单家公司，读取最近约 18 个月的公开日线，并复用现有
一小时、最多四家公司的有限缓存。免费自动部分包括：

- 最新成交量相对此前 20 个交易日成交量中位数的倍数；
- 成交量相对此前最多 250 个有效交易日的历史分位；
- 公开行情源提供的普通换手率；
- 普通换手率相对此前最多 250 个有效交易日的历史分位；
- 最近 20 个交易日内的明显放量、普通换手率高位和两项重合次数；
- 最近 60 个交易日的成交量倍数与普通换手率图；
- 最近 20 个交易日触发固定规则的异常活跃记录。

滚动中位数和历史分位均排除目标交易日自身及未来数据。历史分位至少需要
20 个此前有效交易日。

## 3. 固定观察规则

最新价格—量能组合只使用当日涨跌幅和成交量倍数：

- 成交量倍数不低于 1.3 且当日上涨：放量上涨；
- 成交量倍数不低于 1.3 且当日下跌：放量下跌；
- 成交量倍数不高于 0.7 且当日上涨：缩量上涨；
- 成交量倍数不高于 0.7 且当日下跌：缩量下跌；
- 其他情况：量能接近常态。

历史异常记录沿用现有市场异动规则：

- 明显放量：成交量不低于此前 20 日中位数的 2 倍；
- 普通换手率高位：达到此前最多 250 个有效交易日的 90% 历史分位。

这些名称只是描述已经发生的组合，不是强弱评分或预测模型。

## 4. 普通换手率与有效换手率

普通换手率的常见分母是无限售流通股本。有效换手率进一步使用自由流通股本，
需要排除大股东、战略持股等实际上不易交易的股份。两个指标不能改名混用。

免费版不会自动估算自由流通股本。用户只有在能够提供同一日期、同一单位的
无限售流通股本和自由流通股本，并填写可追溯来源时，才能使用验证模式：

`有效换手率 = 普通换手率 × 无限售流通股本 ÷ 自由流通股本`

该等式复用公开源已经提供的普通换手率，因此不会猜测行情成交量字段究竟以
“股”还是“手”为单位。自由流通股本不能大于无限售流通股本，两个股本值
必须大于零。

## 5. 数据与部署边界

- 页面只在用户打开时读取一家公司的有限日线，不预下载全市场数据；
- 图表最多保留 60 个交易日，异常表最多保留 20 条记录；
- 不创建后台任务、持久化数据库或大型服务器文件；
- 公开源缺少换手率时保留“数据不足”，不转换为 0；
- 数据源失败不会影响年报、公告或其他研究页面；
- 成交量和换手率只能描述参与程度，不能单独证明公司价值或未来方向。
