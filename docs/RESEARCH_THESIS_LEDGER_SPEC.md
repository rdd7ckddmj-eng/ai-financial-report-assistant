# 研究结论账本规格

## 用户问题

普通 AI 可以快速生成一段公司分析，但很难回答三个更重要的问题：最初的判断
是什么、哪些证据能够验证或推翻它、后来为什么修改结论。研究结论账本把一次性
回答变成可追溯的研究过程。

## 一条记录包含什么

- 已核验的上市公司身份；
- 一条可证伪的研究假设；
- 需要出现什么公开证据才算支持；
- 出现什么情况时假设应修改或失效；
- 财务与业绩、经营事项、资本运作、治理与风险或其他主题；
- 人工指定的复核状态和备注；
- 可选的一条通过官方域名校验的证据链接。

## 自动化和人工判断边界

系统可以把 Evidence Delta 中相同主题的公告放到假设旁边，但主题相同不代表
公告支持或反驳假设。系统不得根据标题自动生成利好、利空、看多、看空或买卖
建议。以下四种状态只能由用户阅读原文后选择：待核验、暂有证据支持、出现反方
证据、已失效。

## 本机存储和安全规则

1. 每台设备最多保存10条，避免浏览器状态无界增长；
2. 继续使用现有浏览器存储键，升级时保留旧自选股和证据基准；
3. 浏览器数据进入当前 Streamlit 会话用于显示和生成下载文件；
4. 服务器不建立用户数据库，也不永久保存这些记录；
5. 清除本站浏览数据或更换设备后记录不会自动同步；
6. 不得输入持仓、客户资料、未公开信息、联系方式或其他敏感数据；
7. 证据链接只接受巨潮资讯、上交所、深交所和北交所官方域名；
8. 所有文本都限制长度，导出前执行 HTML 转义。

## 输出

- 每种人工状态的数量；
- 假设、支持条件、失效条件和最近人工备注；
- 可选的官方证据日期、标题和原文链接；
- 可离线保存或打印的中文 HTML 研究底稿；
- 明确的人工判断、隐私和非投资建议说明。

## 后续迁移

当前版本是在暂缓登录系统的条件下验证研究工作流。如果未来加入账户，应把账本
迁移到带用户归属、访问控制和备份的持久数据库；浏览器副本只能作为缓存或离线
草稿，不能继续充当跨设备的权威记录。
