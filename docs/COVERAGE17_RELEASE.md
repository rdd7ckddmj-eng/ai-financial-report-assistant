# 第17批完整年报扩围

本批新增48家公司2025年完整官方年报，沪深两组各24家，合计11,142页。网站的已测试原件目录从204份、188家公司扩至252份、236家公司。新增38份通过自动检查、10份保留缺口；累计225份通过、27份有缺口，211家公司至少有一份候选。这些结果只对应具体原件版本，不代表全部A股或其他年度覆盖，也不是人工财务确认。

本次仅更新目录、版本信息和发布记录，生产解析代码、计算公式、原始金额及资源上限保持不变。252份原件按每批最多40份串行重新解析，原有204份完整回执逐项一致。48份原件均与官方公告、报告年度、公司身份、公告日期、PDF SHA和原生文本页绑定；每份原文经第二次逐页文本复核。中直股份使用最新的2025年更正后年报，保留早期版本公告作为选择依据。贵研铂业的一条下载实际为集团另一主体10页文件，已排除并保留排除记录，未纳入目录。

新增缺口为思源电气、汉钟精机、太极股份、伟星新材、中国国贸、保利发展、中国卫星、首旅酒店、济川药业、豫园股份。未通过三表自动检查的原件，其五项标准化金额继续待核验，能够读取的原文数值及页码仍然保留，不将缺失金额补零。旧17份缺口没有被覆盖或删除。

新增48份共240项本期公开金额对照：186项金额接近（实际差额为零）、4项存在差异、50项不可比。4项差异为裕同科技总资产/总负债与华润双鹤总资产/总负债，原件均对应物理第87、88页。年报减公开源分别为-756,213,617.43、-513,812,948.51、-386,340,056.76、-121,027,549.06元。保留两个来源、实际抓取时间和差异提示；差异原因尚未确认，不推断重述，不覆盖任一来源。另行独立复算240项并逐字段匹配完整对照对象。

目录加入48项实际原件参数用例，原有3971项测试清单全部保留。完整测试和部署结果以发布清单中的原始日志及线上证据为准。计划线上实测8份原件，包括更正后版本、422页年报、亏损公司、两家公开金额差异公司和一份缺口原件；仅在实际操作完成后记录通过，不把本地结果当作部署完成。人工复核与底稿导出门禁保持生效。
