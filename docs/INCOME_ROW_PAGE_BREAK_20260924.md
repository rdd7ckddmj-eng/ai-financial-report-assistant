# 宝钢归母利润注释跨页的原文读取

已视觉核对宝钢股份 600019《2025 年年度报告》物理 97、98 页。97 页先结束母公司资产负债表，再开始明确的合并利润表；其页尾为：

```text
（二）按所有权归属分类
1.归属于母公司股东的净利润（净亏
10,345,621,735.27
7,361,925,588.60
```

98 页按原始提取顺序为年报页眉、`98 / 245`、`损以“-”号填列）`，然后才是少数股东损益。视觉原件确认这是真实跨页表格：两期归母金额在 97 页，98 页仅延续左侧标签括号注释。不能把净利润总额或母公司利润当成替代值。

新增 `src/income_row_layout_recovery.py`，不依赖通用提取器，也不修改传入的 PDF、文本或行顺序。辅助函数 `recover_cross_page_attributable_profit(pages, *, report_year=None)` 接受原始 `(物理页码, text)` 列表：

- 无此类候选返回 `None`，普通完整标签仍走原规则。
- 识别到候选但缺证据返回 `values=None`、明确 `error`；调用者不能继续用其他口径补数。
- 成功返回 `_rows` 兼容的 `label / values / error / pages / excerpt / notes`。金额是 Decimal 两期数；附加 `amount_pages`、`header_years`、`unit`、`currency`、`layout_recovery` 和 `source_segments`。

约束：完整核心标签和精确未完注释前缀；同一报告页眉；页码是真实的相邻 `n / total`；前页存在唯一合并利润表、人民币元、附注五、年度及年度减一双列表头；只消费前页末尾恰好两个两位小数金额；下一页必须立即以精确注释后缀、少数股东完整分行标签、两期金额及下一科目边界衔接。母公司表、额外行、缺行、重复标签、错页码、错表头或未知注释均不能被跳过。

`source_segments` 各自包含物理页码、源页偏移和直接切片文本。展示用 `excerpt` 只按原始顺序连接这些片段，保留中间真实页眉与页码，并不会伪造一个原 PDF 中不存在的连续完整标签。

该函数只证明“这一行的两个明确金额属于这个完整标签”，不验证公司身份，也不靠金额平衡选择或修复数字。修改某个金额为另一明确小数，函数仍返回该原值；调用方必须使用既有三表勾稽拒绝矛盾。真实 245 页 PDF 经既有 `extract_pdf_pages` 默认上限重新抽取后得到归母 `10345621735.27 / 7361925588.60` 元，来源 97–98 页、金额页 97。

最小接入建议：

1. `find_income_statement_figures` 的普通归母行无法读取时，直接向 helper 传入保留页码的原始页列表。只有 `values` 明确成功且表头双期和合并表一致才使用其金额，并保留 `source_segments`；不要生成改写页面再递归解析。
2. `check_general_income_reconciliation` 的归母证据在相同报表范围内使用同一 helper 成功行。已有归母行时不可添加第二行，也不可用 helper 覆盖冲突；损坏候选保留 `missing_evidence`。
3. 两处调用都必须保留原始两期数及 97–98 的来源范围，然后运行既有税前－所得税＝净利润、归母＋少数股东＝净利润检查；本函数不替代检查。
