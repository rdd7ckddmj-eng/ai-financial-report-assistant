# 第13批：利润归属、附注与四列表头的严格核对

本次仅扩展 `general_income_reconciliation.py` 的有界普通公司利润检查。真实原件页文本及元数据保存在 `tests/fixtures/coverage13_income_attribution_columns.json`，测试输入的选定收入/归母值来自对应单元格，不能当作新一轮完整PDF解析回执。完整生产回归由批次任务另外执行。

## 明确独立的其他权益工具持有者净利润

兖矿能源2025年报物理154—155页，单位人民币千元。两期合并净利润关系为：

- 2025：8,380,948（归母股东）+627,530（母公司其他权益工具持有者）+5,217,223（少数股东）=14,225,701。
- 2024：14,862,943+631,864+6,571,047=22,065,854。

视觉核对确认第155页在“按所有权归属分类”下按1、2、3编号独立列示三行。新规则只在明确两列、该分类标题唯一、三行精确标签且编号依次为1/2/3、金额完整时采用第三项。`other_equity_holder_profit` 保留原行金额、页码和摘录；输出归母股东金额仍为8,380,948 / 14,862,943，不与其他权益工具合并输出。

分类标题至其他综合收益标题之间，必须全部由三行实际解析到的标签、注释及数值范围覆盖。单独“其中：”、未知范围说明、重复行或不支持的插入文字都使第三项证据不足；编号本身不能覆盖这些歧义。当前严格版式未支持跨页插入其他标题的第三项，不能默认为独立。缺项不由差额反推，缺少整行时仍按已取得两项计算并报告真实矛盾。其他综合收益中的权益工具投资公允价值变动不属于净利润归属项。

## 附注、母公司不适用栏与续页期间

- 同仁堂2025年报物理76—77页：所得税原文附注 `八、七、76` 被作为限定的“双章、序号”引用读取；原金额393,508,814.56 / 525,045,590.00元不变。新双章和两个括号式引文仅在存在明确附注列时生效；未知后缀和额外数字拒绝。已有明确注号之后，不允许再把多出的首个整数吞作第二个注号。
- 青岛啤酒2025年报物理72页：四列表头明确为“合并、合并、母公司、母公司”，原有“合并、合并、公司、公司”也继续支持，混排或缺列拒绝。少数股东行后两栏的两个 `/` 只在该明确四列版式有效。证据 `values` 后两项为JSON `null`，`raw_values` 保留两个 `/`，`not_applicable_columns` 标明对应母公司列。它们不转换成零，也不进入合并运算；母公司另核对股东净利润等于母公司净利润。
- 特变电工2025年报物理140—142页：所有出现的明确“项目/附注/两年度”重复表头都必须与首表期间一致，包括第141页的中间页。错年度、缺年度、倒序、额外年度及未知年份注释均停止通过，不能只检查首尾两页。

兖矿和同仁堂经营分项中仍存在原文空白项，经营分项增强检查继续保留 `missing_evidence`；青啤四列经营分项继续保留 `unsupported_layout`。三者本次通过的是可追溯的税前至税后及利润归属检查，不宣称全部收入成本分项已完整核对。
