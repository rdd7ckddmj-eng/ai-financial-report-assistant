# 已核验公司扩展 Agent 产品规格

## 1. 一句话定义

已核验公司扩展 Agent 把“寻找年报、逐份提取、跨年核对、人工复核”整理成一条
可追溯的公司接入流程。它用于扩大产品的已核验深度案例层，不试图复制 Wind 等
商业数据库的全市场数据覆盖。

## 2. 用户流程

1. 输入 A 股公司名称或六位股票代码；
2. 从巨潮资讯官方披露目录寻找最近三份不同财务年度的完整年报；
3. 排除摘要、半年报、问询、回复和同年度英文重复版本；
4. 用户每次选择一份报告，服务器临时下载并解析；
5. Python 分别识别并核验合并利润表、合并资产负债表和合并现金流量表；
6. 提取营业收入、净利润、经营现金流净额、总资产和总负债；
7. 比较后续报告的上年比较列与早期报告的首次披露值；
8. 下载带官方链接、PDF 页码、单位和文件指纹的 JSON 候选包；
9. 人工复核通过后，才单独写入受控已核验目录。

## 3. 自动检查

自动阶段只接受受信任的官方披露链接，并检查：

- 最近报告是否覆盖三个连续财务年度；
- 三张合并报表能否完成标签识别和勾稽验证；
- 三张报表的金额单位是否完整且一致；
- 五项核心数值能否从通过核验的报表中取得；
- 每个数值所用报表的 PDF 起止页码；
- 相邻报告中同一财务年度的首次披露值与后续比较列是否变化；
- 本次 PDF 的 SHA-256 文件指纹。

跨报告差异只标记为“重述或口径变化线索”。系统不会自动把差异判定为错误，
也不会自动选择哪个版本写入多年趋势数据。

## 4. 人工确认闸门

候选包始终记录：

- `package_type = audited_company_candidate`；
- `catalogue_written = false`；
- `human_approval_required = true`。

即使三个年度的自动检查全部通过，状态也只是
`ready_for_human_review`，不是 `verified`。人工复核至少包括：

1. 打开官方 PDF 核对公司、年度、合并口径和页码；
2. 确认元、千元、万元等金额单位并统一换算；
3. 阅读会计政策或前期差错说明，判断跨报告差异原因；
4. 确认连续年度数据后，再创建受控 CSV 和目录记录；
5. 运行现有目录审计测试后，才能在财务趋势实验室展示。

## 5. 免费服务器边界

- 年报 PDF 按用户请求临时下载，不提前批量下载全市场报告；
- 每次只解析一份 PDF，自动载入大小上限为 32 MB；
- 解析后只把小型候选结果保存在当前会话，不长期保存 PDF 和全文；
- 无需登录系统、数据库、持久磁盘或付费 AI API；
- 页面关闭、服务器重启或重新部署后，未下载的候选会话可能消失，用户可通过
  JSON 候选包保留本次工作。

## 6. 当前适用范围与限制

第一版面向采用常见非金融企业合并报表结构的 A 股上市公司。银行、保险、证券等
特殊行业报表科目不同，自动识别失败时必须停止并转为人工接入，不能用 AI 补数字。

文件指纹用于识别本次证据文件，不是数字签名、审计意见或第三方认证。本功能不
评价公司质量，不预测股价，也不提供买入、卖出或持有建议。
