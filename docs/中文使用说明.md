# WFZ AI 财报智能分析助手——中文使用说明

## 一、产品信息

- 产品名称：WFZ AI 财报智能分析助手
- 产品设计与研发：王方正
- 学校：Durham University
- 主要用途：国内求职面试演示、个人作品集、财务分析学习
- 使用边界：本产品用于教育和财务分析演示，不构成投资建议

## 二、产品能做什么

本产品把财务分析、PDF 证据检索和多 Agent 工作流结合在一个网页中，主要功能包括：

1. 上传公开发布的年度报告 PDF，并按原始页码提取文本。
2. 自动识别利润表、资产负债表和现金流量表中的关键数据。
3. 使用 Python 计算净利润率、营业收入增长率、流动比率和资产负债率。
4. 用自然语言向年报提问，并显示带 PDF 页码的证据。
5. 通过 Router、Retriever、Analyst、Skeptic 和 Verifier 的协作流程进行检索、分析、质疑与验证。
6. 下载完整的 Agent 审计记录，便于复核系统采用了哪些证据。
7. 使用人民币、英镑、美元或欧元输入并演示手工财务指标计算。
8. 在有 OpenAI API 额度时，调用可选的 LLM 综合分析；没有额度时，仍可使用本地检索、计算和验证功能。

## 三、开始使用

如果网页已经打开并显示产品首页，就不需要另外打开 Python。当前本地演示地址通常为：

`http://localhost:8502`

如果网页没有运行，需要在项目环境中启动 Streamlit 应用。求职演示前，建议提前打开网页并完成一次测试。

## 四、年度报告分析操作步骤

### 第一步：上传年报

点击“上传年度报告 PDF”，选择公开发布的年报文件。不要上传个人银行资料、客户资料或其他机密文件。

### 第二步：检查自动提取结果

上传成功后，系统会显示：

- PDF 文本预览和原始页码；
- 收入与利润；
- 流动性；
- 杠杆与资本结构；
- 现金流。

系统会对关键报表关系进行勾稽核对。若报表结构不符合预期，提取器会停止，不会猜测财务数字。

### 第三步：向年报提问

在“基于证据向年报提问”区域输入问题，例如：

- 为什么经营现金流增加？
- 本期营业收入增长率是多少？
- 总负债是多少？
- 管理层对流动性风险作出了什么说明？

点击“生成带页码的证据答案”。

### 第四步：阅读分析链条

回答区域会依次展示：

1. Agent Router 选择的工作流；
2. Python 财务计算工具的公式和输入；
3. 动态升级原因；
4. 多 Agent 执行轨迹；
5. 基于证据的结论；
6. Skeptic Mode 的反方检查；
7. Verifier Agent 的输出审计；
8. 年报原文和 PDF 页码。

年报原文会保留原始语言，不进行改写，这样可以直接与 PDF 核对，确保引用可追溯。

### 第五步：下载审计记录

点击“下载 Agent 审计记录（JSON）”，可以保存本次分析使用的路由、证据、页码、质疑和验证结果。

## 五、人民币财务指标演示

在“手工财务分析工具”中，将“显示货币”选择为：

`CNY (¥ 人民币)`

人民币已经设为默认选项。然后输入金额并计算：

- 净利润率 = 净利润 ÷ 营业收入
- 营业收入增长率 =（本期收入 − 上期收入）÷ 上期收入
- 流动比率 = 流动资产 ÷ 流动负债
- 资产负债率 = 总负债 ÷ 总资产

货币选择只改变金额的业务含义，不改变比率公式。

## 六、三分钟面试演示流程

### 0:00—0:30：说明问题

“传统年报分析耗时，而且生成式 AI 可能编造数字。这个产品把 Python 的确定性计算、PDF 页码溯源和多 Agent 验证结合起来，重点解决财务结论的可靠性问题。”

### 0:30—1:15：展示自动提取

上传一份已经测试过的公开年报，展示系统自动识别利润表、资产负债表和现金流量表，并说明数字由 Python 提取和勾稽，不由 LLM 猜测。

### 1:15—2:15：展示 Agent 问答

输入“为什么经营现金流增加？”，依次展示 Router、证据检索、Skeptic Mode、Verifier 和 PDF 原文页码。强调每个结论都可以回到原始年报复核。

### 2:15—3:00：说明创新与边界

“产品的差异不只是聊天界面，而是可审计的 Agent 工作流：系统会根据问题类型选择不同分析深度，在证据不足时自动升级，并对数字、页码和反方证据进行本地验证。它不提供投资建议，证据不足时会拒绝回答。”

## 七、产品的安全与严谨设计

- 财务公式由 Python 执行，LLM 不负责重新计算关键数字。
- 每条年报证据保留 PDF 页码。
- Skeptic Mode 主动寻找限制、抵销因素和反方证据。
- Verifier Agent 检查证据门槛、引用页码和输出一致性。
- 证据不足时安全拒答，不强行生成看似完整的结论。
- API 密钥保存在本机环境文件中，不显示在网页或审计记录里。
- 产品明确声明不构成投资建议。

## 八、已知限制

- Tesco PLC 2026 年报是当前测试最充分的样本，其他公司的报表版式可能需要适配。
- 扫描图片型 PDF 可能无法直接提取文字，需要增加 OCR 功能。
- LLM 综合分析需要单独的 OpenAI API 额度；ChatGPT 订阅不等于 API 额度。
- 当前版本是作品集和求职演示产品，不是覆盖所有会计准则和报表格式的商业系统。
- 自动分析不能替代专业判断，结论应结合行业、历史趋势、会计政策和商业模式复核。

## 九、常见问题

### 1. 页面提示 API 额度不足怎么办？

关闭“使用 LLM 综合分析”即可。本地 PDF 检索、Python 计算、Skeptic Mode 和 Verifier 仍然可以正常运行。

### 2. 某一页显示没有可提取文本怎么办？

该页可能是扫描图片。可以更换带文本层的 PDF，或在未来版本中加入 OCR。

### 3. 为什么系统没有回答问题？

系统可能没有找到足够强的证据。请使用更具体的财务术语，或确认年报中确实包含相关内容。

### 4. 为什么分母为零时不计算？

净利润率、增长率、流动比率和资产负债率都涉及除法。分母为零时结果没有可解释的财务意义，因此系统会停止并显示原因。

### 5. 为什么年报证据仍然是英文？

这是有意保留的设计。英文原文与原始 PDF 完全对应，便于复核和追溯；产品导航、操作提示和计算解释已经中文化。

## 十、面试总结话术

“这是我独立设计和研发的 AI 财报智能分析助手。我没有让大模型直接猜财务数字，而是让 Python 负责确定性计算，让每条结论保留 PDF 页码，再通过多 Agent 工作流进行路由、质疑和验证。这个设计重点解决的是财务 AI 的可靠性、可追溯性和安全边界问题。”
