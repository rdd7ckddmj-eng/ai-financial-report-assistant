# WFZ 中国上市公司自主研究 Agent——中文使用说明

## 一、产品信息

- 产品名称：WFZ 中国上市公司自主研究 Agent
- 核心模块：上市公司检索、官方动态墙、K 线与市场表现、Historical Lens、年报证据分析
- 产品设计与研发：王方正
- 学校：Durham University（杜伦大学）
- 主要用途：国内求职面试演示、个人作品集、财务分析学习
- 使用边界：本产品用于自主研究和教育，不预测短期涨跌，不构成投资建议

## 二、产品能做什么

用户输入中国上市公司的名称或六位股票代码后，系统会把同一家公司的研究对象带到各个子页面。

1. 核验公司代码、名称及所属的上海、深圳或北京证券交易所。
2. 按需同步巨潮资讯公开公告，显示公告日期、类别、关注程度和原始链接。
3. 自动寻找最新完整年度报告，排除摘要、取消公告、问询函和回复。
4. 从官方披露地址临时载入年度报告 PDF，减少用户手工下载步骤。
5. 在官方自动载入失败时保留手工上传入口，不用未经核验的材料代替。
6. 展示日 K 线、成交量和 MA5、MA20、MA60 移动平均线。
7. 用 Python 计算 20 日、60 日、250 日收益率、年化历史波动率和最大回撤。
8. 展示最新日涨跌幅、成交量相对前 20 日中位数、普通换手率数据状态和涨停候选。
9. 选择历史截止日，只用当时已经公开的信息建立研究快照。
10. 由用户主动揭示后来 1、3、6 个月的市场表现，防止未来信息泄漏。
11. 提取年报文字并保留 PDF 页码，计算财务指标并回答带证据的问题。
12. 通过 Router、Retriever、Analyst、Skeptic 和 Verifier 展示可审计的 Agent 工作流。
13. 在有 OpenAI API 额度时进行可选的 LLM 综合；没有额度时仍可使用检索、计算、公告、K 线和验证功能。

## 三、网站页面

### 1. 首页

输入公司名称或六位股票代码，例如“贵州茅台”或“600519”。如果公司名称对应多个结果，系统会让用户确认，不会擅自选择。

### 2. 公司研究中心

集中展示：

- 公司名称、股票代码和交易所；
- 最新收盘价及透明计算的市场指标；
- 最新完整年度报告入口；
- 最近官方公告动态墙；
- 前往 K 线和年报分析的快捷入口。

“关注程度”只代表建议优先阅读的程度，不表示利好或利空。

### 3. K 线与市场表现

可选择近一年、近三年或近五年，以及前复权、不复权或后复权口径。不同复权口径不能混在一起比较。

页面展示：

- 日 K 线；
- 成交量；
- MA5、MA20、MA60；
- 20 日和 60 日收益率；
- 年化历史波动率；
- 区间最大回撤。

页面还会单独展示“市场活跃度证据”：

- 最新交易日涨跌幅；
- 当日成交量相对于此前 20 个交易日成交量中位数的倍数；
- 成交量和普通换手率相对于此前最多 250 个有效交易日的历史分位；
- 公开行情源是否提供普通换手率；
- 按股票板块和风险警示标识得到的“涨停候选”。

历史分位至少需要 20 个此前有效交易日，不包含当前交易日或任何未来
数据。50% 表示接近历史样本中间位置；高分位只表示相对更活跃，不代表
未来涨跌。普通换手率历史分位仍不等同于有效换手率。

“异常交易日回看 Agent”会继续扫描最近 250 个交易日，列出成交量达到
此前 20 个交易日中位数 2 倍的日期，以及达到板块规则参考阈值的涨停
候选日。每条结果显示日期、日涨跌幅、成交量倍数、普通换手率，以及在
该日当时可以计算的成交量和普通换手率历史分位。点击“回到当天研究”后，
系统会把该日期带入 Historical Lens；公告仍然按照当时的公开日期过滤，
后来行情仍需用户主动揭示。

进入 Historical Lens 后，“异动—公告证据链”会检查所选日期及此前六个
自然日内已经公开的官方公告，显示公告与异常日相隔几天并保留原文链接。
截止日后的公告会被排除。时间接近只代表值得进一步核验，不代表公告导致
了价格或成交量变化。

“涨停候选”不是交易所最终认定。系统会保留新股上市初期、重新上市、
退市整理首日、价格最小变动单位等例外提示。普通换手率也不会被冒充为
“有效换手率”；后者需要可核验的时点自由流通股本作为分母，当前缺少该
证据时会明确显示“暂不计算”。

涨跌幅参考规则截至 2026 年 7 月 30 日，依据
[上交所 2026 年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、
[深交所主板规则说明](https://investor.szse.cn/knowledge/qa/t20230306_599093.html)和
[北交所 2026 年交易规则](https://www.bse.cn/jygl_list/200028217.html)。

这些数据只描述已经发生的历史表现，不能单独证明公司价值，也不能预测未来价格。

### 4. Historical Lens

选择一个历史研究截止日后，系统会：

- 为贵州茅台提供三个已经人工核验、带官方原文链接的重要日期；
- 继续允许用户自由选择其他历史日期；
- 使用该日期之前最近一个交易日作为有效行情日；
- 用截止日前的数据重新计算收益率、波动率和最大回撤；
- 只显示发布日期不晚于截止日的官方公告；
- 自动整理所选日期最近七个自然日的“异动—公告证据链”；
- 同时记录用户选择日期和实际采用交易日；
- 默认隐藏后来行情，直到用户点击“揭示后来 1、3、6 个月的市场表现”。

历史页面默认使用不复权价格，避免今天的复权因子把后来发生的分红、送转等信息
带回过去。后来结果只用于复盘，不能证明某一公告造成了价格变化。

### 5. 年报与证据

选择公司后，页面会尝试找到最新完整年度报告。点击“自动载入并分析”后，服务器会从受信任的巨潮资讯地址临时读取 PDF，并进入原有证据分析流程。

自动载入有三层保护：

- 只接受巨潮资讯等允许的官方披露域名；
- 限制文件大小；
- 检查文件是否具有有效 PDF 标识。

如果官方站点限流、报告过大或链接结构发生变化，请打开官方原文下载 PDF，再使用手工上传入口。

### 6. 方法与审计

说明数据来源优先级、Python 与 AI 的分工、已知限制和产品边界，方便面试官或用户检查系统是否严谨。

## 四、动态墙是否需要每天人工更新

不需要每天手工更新。用户进入公司研究页面时，系统会按需读取公开公告，并缓存一小时：

- 一小时内重复查看同一家公司，会优先使用缓存，减少对公开数据源的压力；
- 缓存到期后再次访问，系统会重新请求最新公告；
- 当前版本不设置全天候后台定时任务，因此不会产生长期运行的额外服务器成本；
- 未来有稳定用户量后，再评估定时更新和推送。

这是一种适合自费早期产品的做法：用户看到的是自动更新，开发者不需要每天人工维护。

## 五、哪些功能需要付费 API

下列功能首版不需要 OpenAI 付费 API：

- 公司名称和股票代码检索；
- 官方公告动态墙；
- K 线与市场指标；
- 官方年报定位和临时载入；
- PDF 文字提取；
- Python 财务计算；
- 本地证据检索、Skeptic 和 Verifier。

只有可选的自然语言 LLM 综合需要单独的 OpenAI API 额度。ChatGPT 订阅与 OpenAI API 账单是两套系统。

## 六、年度报告分析步骤

### 第一步：取得报告

优先点击“自动载入并分析”。如果失败，点击“查看官方原文”，下载公开年度报告后手工上传。不要上传个人银行资料、客户资料或其他机密文件。

### 第二步：检查自动提取结果

系统会显示 PDF 文本预览、原始页码和能够识别的报表数据。关键报表关系会进行勾稽核对；报表结构不符合预期时，系统应停止并提示，而不是猜测数字。

### 第三步：向年报提问

可以输入：

- 为什么经营现金流增加？
- 本期营业收入增长率是多少？
- 总负债是多少？
- 管理层对流动性风险作出了什么说明？

### 第四步：阅读分析链条

回答区域依次展示 Agent 路由、Python 计算、动态升级、多 Agent 轨迹、证据结论、Skeptic 质疑、Verifier 审计和 PDF 页码。

### 第五步：下载审计记录

点击“下载 Agent 审计记录（JSON）”，保存本次分析采用的路由、证据、页码、质疑和验证结果。

## 七、人民币财务指标演示

在手工财务分析工具中选择 `CNY (¥ 人民币)`，然后输入同一口径、同一报告期的金额。

- 净利润率 = 净利润 ÷ 营业收入
- 营业收入增长率 =（本期收入 − 上期收入）÷ 上期收入
- 流动比率 = 流动资产 ÷ 流动负债
- 资产负债率 = 总负债 ÷ 总资产

货币选择只改变金额的业务含义，不改变公式。

## 九、严谨性设计

- 财务比率和市场指标由 Python 计算，LLM 不负责重新计算关键数字。
- K 线数据先检查日期、数值类型和开高低收关系。
- Historical Lens 按公开发布日期过滤证据，报告期不能代替发布日期。
- 当时快照与后来结果由不同 Python 函数生成，防止未来数据混入。
- 异动—公告证据链排除未来公告，并明确禁止把时间接近当作因果结论。
- 公告只展示允许的官方域名，并保留原始链接。
- 年报自动载入前检查官方来源、文件大小和 PDF 标识。
- 每条年报证据尽量保留 PDF 页码。
- 数据不足不显示为 0，而是明确标记“数据不足”。
- Skeptic 主动寻找限制和反方证据。
- Verifier 检查证据门槛、引用页码和输出一致性。
- API 密钥保存在服务器环境变量中，不写入代码仓库。

## 十、已知限制

- 公开数据源可能限流、暂时不可访问或改变字段。
- 当前自动年报定位主要依赖巨潮资讯；其他交易所链接会保留原文但不一定能自动载入。
- 中国上市公司报表版式和行业差异较大，银行、保险和普通工业企业需要分别适配。
- 现有确定性提取器对 Tesco PLC 2026 年报测试最充分，中国年报自动提取仍属于扩展阶段。
- 扫描图片型 PDF 可能需要 OCR。
- 前复权行情来自公开行情适配器，不等于交易所原始逐笔数据。
- 媒体新闻尚未加入首版，因为来源质量、版权和“利好/利空”误判风险高于官方公告。
- Historical Lens 可计算任意可取得行情日期的市场快照，并已为贵州茅台
  加入三个带官方来源的重要时点及确定性的异动—公告证据链；扩展到五个
  人工核验时点仍在建设中。

## 十一、常见问题

### 1. 页面提示公开数据源不可用怎么办？

稍后刷新。官方公告和行情故障彼此隔离；年报手工上传和已有本地计算仍可使用。

### 2. 为什么输入陌生代码时显示“待核验公司”？

实时公司目录暂时不可用时，系统只能根据代码规则判断交易所。名称未核验前不要据此形成结论，待数据源恢复后重新搜索。

### 3. 为什么自动载入年报失败？

可能是官方站点限流、文件过大或链接结构变化。打开官方原文下载 PDF，再手工上传即可。

### 4. 为什么系统没有给出利好或利空？

公告标题不足以可靠判断对公司价值的影响。系统只标记阅读优先级，避免伪装成确定结论。

### 5. 为什么分母为零时不计算？

净利润率、增长率、流动比率和资产负债率都涉及除法。分母为零时没有可解释的财务意义，因此系统会停止并显示原因。

## 十二、面试总结话术

“这是我独立设计和研发的中国上市公司自主研究 Agent。用户输入公司名称或股票代码后，系统按需连接官方公告、历史行情和年度报告。Python 负责确定性计算，官方链接和 PDF 页码负责追溯，多 Agent 工作流负责路由、质疑和验证。它的目标不是预测涨跌，而是提高自主研究的效率与可靠性。”
