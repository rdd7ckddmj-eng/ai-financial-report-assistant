# WFZ 中国上市公司自主研究 Agent——中文使用说明

## 一、产品信息

- 产品名称：WFZ 中国上市公司自主研究 Agent
- 一级模块：首页、《消失的现金》、上市公司研究中枢
- 研究中枢的五个任务集合：发现研究对象、完成公司初研、调查市场事件、
  核验财务证据、跟踪与治理研究
- 核心研究工具：一键综合研究 Agent、上市公司检索、官方动态墙、K 线与市场表现、成交量与换手率研究、每日涨停板观察台、自选股研究任务队列、市场异动研究 Agent、历史时点复盘（Historical Lens）、全市场按需财务快照 Agent、年报证据分析、已核验公司扩展 Agent、财务趋势实验室、财务异常解释 Agent、跨公司横向比较
- 产品设计与研发：王方正
- 学校：Durham University（杜伦大学）
- 主要用途：国内求职面试演示、个人作品集、财务分析学习
- 使用边界：本产品用于自主研究和教育，不预测短期涨跌，不构成投资建议

## 二、产品能做什么

用户输入中国上市公司的名称或六位股票代码后，系统会把同一家公司的研究对象带到各个子页面。

1. 核验公司代码、名称及所属的上海、深圳或北京证券交易所。
2. 按需同步巨潮资讯公开公告，显示公告日期、类别、关注程度和原始链接。
3. 自动寻找最新完整年度报告，排除摘要、取消公告、问询函和回复。
4. 从官方披露地址临时载入年度报告 PDF，减少用户手工下载步骤。
5. 在官方自动载入失败时保留手工上传入口，不用未经核验的材料代替。
6. 展示日 K 线、成交量和 MA5、MA20、MA60 移动平均线。
7. 用 Python 计算 20 日、60 日、250 日收益率、年化历史波动率和最大回撤。
8. 展示最新日涨跌幅、成交量相对前 20 日中位数、普通换手率数据状态和涨停候选。
9. 单独研究成交量倍数、普通换手率、近 20 日活跃次数，并在具有可追溯
   自由流通股本时验证有效换手率。
10. 按交易日读取公开涨停股池，展示连板、成交额、普通换手率、封板时间、
   涨停梯队、行业结构和回封记录。
11. 一次按需扫描最多五家自选股，结合行情异动和近45日官方公告生成 P1/P2/P3 研究任务队列。
12. 用市场异动 Agent 综合价格、成交量和普通换手率历史位置，并连接官方公告证据。
13. 选择历史截止日，只用当时已经公开的信息建立研究快照。
14. 由用户主动揭示后来 1、3、6 个月的市场表现，防止未来信息泄漏。
15. 提取年报文字并保留 PDF 页码，计算财务指标并回答带证据的问题。
16. 用已核验多年年报计算收入、利润、经营现金和负债结构趋势，并保留报告版本。
17. 通过 Router、Retriever、Analyst、Skeptic 和 Verifier 展示可审计的 Agent 工作流。
18. 在有 OpenAI API 额度时进行可选的 LLM 综合；没有额度时仍可使用检索、计算、公告、K 线和验证功能。
19. 一键串联公司身份、行情活跃度、官方公告、最新年报和财务证据，生成带
    证据状态、执行轨迹和限制说明的综合研究简报；多年已核验数据优先，普通
    公司可复用当前会话中已生成的单期财务快照。
20. 对“收入和利润增长、经营现金流下降”等异常方向进行确定性扫描，逐项勾稽年报现金流调节表，区分已证实桥接与待核查原因。
21. 为候选公司发现最近三份完整年报，逐份核验三张报表、五项核心数值、
    金额单位和跨年重述线索，生成等待人工确认的 JSON 接入包。
22. 为用户主动选择的普通 A 股公司临时处理一份最新完整年报，生成带官方
    链接、PDF 页码和人工复核状态的单期财务快照，不预先囤积全市场 PDF。

## 三、网站页面

### 1. 《消失的现金》

点击左侧《消失的现金》会直接进入完整游戏画面。建立调查员代号与阅读守则
就是游戏序章本身，不经过网站式介绍页；
随后必须依次完成 01 入局、02 教学、03 练习、04 探索、05 研读、
06 核验、07 证据链、08 判断和 09 迁移，不能跳关。正式判断共用三条生命；迁移关不扣
生命，但玩家必须离开案件，在上市公司研究中枢中自行找到能够冻结信息截止线
的工具，再找对证据第一次可见日，并区分证据公开日、实际采用的 K 线日期、
下一交易日和因果边界。

03 练习不是普通选择题页面。玩家先点击四张带日期的事件卡，把“业务完成、客户
验收、费用支付、客户回款”按发生先后排入时间轴；顺序正确后，利润与现金的双表
计算终端才会解锁。事件顺序或计算答错均不扣生命，但会立即更换整份业务档案，
包括日期、金额和卡片排列。

游戏路线采用固定全屏画面，浏览器外层页面不再上下滚动。某一幕的线索或文件
较多时，只在案件画面内部的内容区滚动，案件编号、当前场景、进度和退出入口
始终留在同一屏幕中。

浏览器允许网站本地存储时，当前关卡、剩余生命、答题轮次和通关状态会保存在
当前浏览器、当前网站域名。刷新页面、退出后重新打开或手机误触不会让玩家回到第一关。它不按
调查员代号或 IP 建档；不同浏览器中的同名互不影响，同一浏览器只保留一份当前
进度。更换设备、换浏览器或清理该网站的浏览器数据后不会自动同步。

九幕完整通关后，页面会解锁亮色横版“研究员荣誉档案”。通关位次是当前
浏览器保存的测试赛季记录，不是全站排名；位次显示为 1、10、100，荣誉编号
显示为 000001、000010。用户还可以下载 1080×1920 的抖音竖版 PNG。档案只
用于记录学习成就，不代表职业资格、执业许可或投资能力认证。

### 2. 首页与研究中枢

首页是网站根页面，提供《消失的现金》和上市公司研究中枢两个主入口。
点击《消失的现金》后直接进入案件屏幕；取代号、阅读调查守则以及
01—09 全部属于同一个游戏舞台，不经过介绍页面，也不跳转到九个独立网页。
进入研究中枢后，左侧会显示五个研究任务集合；展开某个集合后，才继续打开
其中的专项工具，避免所有功能平铺在同一层。

在研究中枢输入公司名称或六位股票代码，例如“贵州茅台”或“600519”。系统会
核验公司身份，并让同一研究对象进入后续子工具。如果公司名称对应多个结果，
系统会先让用户确认，不会擅自选择。

网站会根据页面宽度自动选择窄屏手机布局或宽屏电脑布局。若比例不合适，可在左侧
“选择浏览设备”中手动选择“手机”或“电脑”；正确选择会让图表、线索和操作区
更清楚，选择会保存在当前浏览器。

首页把覆盖范围分成两层，避免把“可以按需查询”误写成“已经完成深度审计”：

- **A 股按需研究层：** 面向沪、深、北交易所上市公司代码，按需读取公司
  身份、公开日线、官方公告和最近年报入口；结果取决于公开数据源当次是否可用。
- **已核验深度案例层：** 当前包含贵州茅台、五粮液、泸州老窖、宁德时代、
  比亚迪和美的集团，共 21 个财务期间、23 个发布版本。只有通过身份、官方来源、页码、
  年度连续性和会计口径检查的资料才进入多年趋势与横向比较。

本产品不是实时交易终端或商业金融数据库的替代品，不包含机构内部路演、持仓
资料或未公开信息，也不生成股价预测和买卖建议。

### 3. 一键综合研究 Agent

从上市公司研究中枢提交公司搜索后，系统会自动运行一次；如果只是从侧边栏直接打开本页，
则仍需点击“运行一键综合研究 Agent”，避免页面浏览触发非预期的数据请求。
已有结果时可点击“重新运行并刷新公开数据”。每次运行都会独立检查五条证据链：

- 上市公司身份；
- 历史行情和最新交易活跃度；
- 巨潮资讯或交易所官方公告；
- 最新完整年度报告；
- 财务证据：优先读取已完成逐页核验的多年历史；没有时，只复用当前会话中
  同一家公司已经生成的单期财务快照。

运行完成后，第一屏先显示“公司研究结论卡”，而不是要求用户逐个阅读所有
模块。结论卡只回答：当前最值得先核验的问题、证据依据、下一步问题，以及
财务、市场、官方动态三项状态。若证据覆盖率低于 50%，系统会优先提示补齐
证据；若规则未触发异常，也只写“未触发预设异常”，不会写成公司安全、优质
或值得买入。页面上的排序是阅读顺序，不是公司评分、上涨概率或投资建议。

每条证据链会显示“已核验”“部分证据”或“暂不可用”。页面中的证据覆盖率
只表示本次取得了多少类数据，不是公司质量评分、上涨概率或投资排名。某一个
公开来源暂时失败时，其他证据链仍会继续，系统不会用旧样例、零值或 AI 猜测
填补缺口。

综合研究不会在后台再次下载和解析大型年报 PDF。普通公司如果暂时没有财务
证据，页面会引导到“全市场按需财务快照 Agent”。生成快照后返回并重新运行，
第五条证据链会显示为“部分证据”，列出五项核心金额、比例、官方链接和 PDF
页码。它始终标注“待人工复核”，不会冒充已核验多年财务历史。

页面还会展示确定性研究观察、六步 Agent 执行轨迹和下一步核验任务。点击
“下载综合研究简报（HTML）”可保存离线报告；报告保留官方链接、计算依据、
失败状态和研究限制，也可以通过浏览器打印为 PDF。点击“下载可审计数据包
（JSON）”可保存同一份结构化证据、Agent 轨迹和 SHA-256 证据指纹，便于系统
复核或后续分析；证据指纹不是数字签名或第三方认证。如果本次研究由自选股雷达
发起，两种下载都会单独保留雷达扫描日期、研究顺序、触发证据、任务原因和最近
官方公告线索，并明确说明这些内容不参与证据覆盖率和财务结论。

如果从“自选股研究任务队列”点击“生成完整研究简报”进入，本页会先显示一张
“由自选股雷达触发”的入口卡片，保留当时的 P1/P2/P3 顺序、行情信号、研究原因
和最近官方公告线索。跳转本身不会自动请求数据；仍需点击运行按钮，五条证据链
会重新独立核验。入口线索不是投资结论，切换到其他公司后也不会串用上一家公司
的雷达信息。

### 4. 公司研究中心

集中展示：

- 公司名称、股票代码和交易所；
- 最新收盘价及透明计算的市场指标；
- 最新完整年度报告入口；
- 最近官方公告动态墙；
- 前往 K 线和年报分析的快捷入口。

“关注程度”只代表建议优先阅读的程度，不表示利好或利空。

### 5. K 线与市场表现

可选择近一年、近三年或近五年，以及前复权、不复权或后复权口径。不同复权口径不能混在一起比较。

页面展示：

- 日 K 线；
- 成交量；
- MA5、MA20、MA60；
- 20 日和 60 日收益率；
- 年化历史波动率；
- 区间最大回撤。

页面还会单独展示“市场活跃度证据”：

- 最新交易日涨跌幅；
- 当日成交量相对于此前 20 个交易日成交量中位数的倍数；
- 成交量和普通换手率相对于此前最多 250 个有效交易日的历史分位；
- 公开行情源是否提供普通换手率；
- 按股票板块和风险警示标识得到的“涨停候选”。

历史分位至少需要 20 个此前有效交易日，不包含当前交易日或任何未来
数据。50% 表示接近历史样本中间位置；高分位只表示相对更活跃，不代表
未来涨跌。普通换手率历史分位仍不等同于有效换手率。

### 6. 成交量与换手率研究

该页面把“成交量”“普通换手率”和“有效换手率”分开处理。自动部分会
展示：

- 最新成交量相对此前 20 日中位数的倍数；
- 成交量和普通换手率相对此前最多 250 个有效交易日的历史分位；
- 最近 20 个交易日的明显放量、普通换手率高位及两项重合次数；
- 最近 60 个交易日的成交量倍数和普通换手率图；
- 触发固定活跃度规则的历史日期。

滚动基准排除当日和未来数据。页面把价格和量能组合描述为“放量上涨”、
“放量下跌”“缩量上涨”“缩量下跌”或“量能接近常态”，这些只是历史
事实标签，不表示下一交易日方向。

有效换手率验证模式是可选功能。只有用户能够提供同一日期、同一单位的
无限售流通股本与自由流通股本，并填写可追溯来源时，系统才计算：

`有效换手率 = 普通换手率 × 无限售流通股本 ÷ 自由流通股本`

免费版不会自动估算自由流通股本，也不会把普通换手率改名为有效换手率。

行情价格与普通换手率优先来自腾讯财经同一份原始日线。腾讯原始行本身含有
换手率，但常用第三方适配器只保留前六列，因此系统改为使用有超时、分段日期
区间、并发数量和响应大小上限的轻量读取器，保留需要的字段。3年、5年行情会
拆成少量请求后按日期合并。只有腾讯失败时才使用东方财富备用源，也不会恢复
会增加免费服务器内存压力的新浪全历史解码。

### 7. 每日涨停板观察台

选择一个近期交易日，点击“读取该日涨停板”。系统会按需读取东方财富公开
涨停股池，并确定性计算：

- 当日涨停、首板和连板家数；
- 最高连板数；
- 普通换手率中位数；
- 涨停公司数量最多的行业；
- 一板到高位连板的完整涨停梯队；
- 行业涨停家数、连板家数、合计成交额和普通换手率中位数；
- 有效记录中 10:00 前首次封板和开板后回封的数量、占比。

默认研究顺序依次比较连板数、炸板次数、首次封板时间、封板资金和普通
换手率。页面展示头部五家公司和前 30 家观察表，点击公司可进入公司研究
中心。该顺序不是 AI 评分，也不代表买入优先级。

“盘后市场结构复盘”使用固定 Python 规则归纳梯队、行业、封板节奏和回封
记录，并明确显示计算分母。行业集中程度只描述当日涨停公司的分布，不代表
市场情绪评分，也不预测下一交易日。

公开涨停股池只提供近期数据。周末、休市日、没有涨停公司或公开源尚未更新
时，可选择前一个交易日。页面只发出一次有数量上限的股池请求，不逐只下载
全市场历史行情，也不需要付费 API。

页面显示的是普通换手率，不是有效换手率。可靠的时点自由流通股本目前需要
额外数据权限，因此系统不会自行估算或改名冒充。

### 8. 自选股研究任务队列

输入最多五个以逗号、空格、分号或顿号分隔的六位股票代码，点击“开始扫描
自选股”。系统会逐家公司读取最新公开行情，并比较：

- 是否达到板块涨停参考阈值；
- 成交量是否达到此前 20 个交易日中位数的 2 倍；
- 普通换手率是否达到此前最多 250 个交易日的 90% 历史分位。

行情扫描后，系统还会查询近45日巨潮资讯官方公告，只展示通过日期和
官方域名校验的原文。优先级规则为：

- P1｜立即核查：同时触发两项及以上行情异动，或两天内有高关注官方公告；
- P2｜优先复盘：触发一项行情异动，或七天内有高/中关注官方公告；
- P3｜常规跟踪：其他已完成扫描的公司。

页面会解释每家公司的任务原因，并保留最近官方公告原文链接。公告标题
“高/中/低关注”只表示建议阅读的先后，不表示利好或利空。P1/P2/P3也不是
投资评分。单家公司的公告源暂时失败时，已核验的行情结果仍然保留，且不会
用新闻摘要或 AI 猜测替代。

点击“下载自选股研究任务简报（HTML）”，可以保存一份离线打开的中文报告。
报告包含 P1/P2/P3、任务原因、市场指标、行情与换手率来源、最近官方公告原文
以及未完成扫描的记录。导出只使用页面已经核验的数据，不会再次请求公开源，
因此不会额外增加免费服务器的分析内存压力。需要 PDF 时，可在浏览器中选择
“打印”并另存为 PDF。

点击“生成完整研究简报”可把当前公司的任务顺序、触发证据、研究原因和最近
公告线索带入一键综合研究 Agent；点击“异动复盘”可继续复盘历史异常日期，
点击“公司资料”可查看更完整的公告墙和年报入口。核心功能不需要付费 API。

### 9. 市场异动研究 Agent

该页面会先分别核验涨停候选、成交量异动和普通换手率历史位置，再生成
“复合异动候选”“单一异动线索”“未发现强异动”或“证据不足”的综合状态。
综合状态只用于安排研究顺序，不代表买入或卖出方向。

Agent 会扫描最近 250 个交易日，列出成交量达到
此前 20 个交易日中位数 2 倍的日期，以及达到板块规则参考阈值的涨停
候选日；如果普通换手率达到此前最多 250 个交易日的 90% 历史分位，
也会进入候选。每条结果显示日期、日涨跌幅、成交量倍数、普通换手率，
以及当时可以计算的历史分位。

选择候选日期后，“异动—公告证据链”会立即检查所选日期及此前六个
自然日内已经公开的官方公告，显示公告与异常日相隔几天并保留原文链接。
截止日后的公告会被排除。时间接近只代表值得进一步核验，不代表公告导致
了价格或成交量变化。点击“进入 Historical Lens 完整复盘”后，系统会
带入该日期；公告仍按公开日期过滤，后来行情仍需用户主动揭示。

“历史相似异动”会在更早的候选日期中比较信号组合、日涨跌幅、成交量
倍数和普通换手率历史分位，显示最多三个达到最低门槛的规则匹配。缺失
字段会从计算中排除，并按剩余字段重新分配权重，不会按 0 处理。用户可
将任一更早日期一键送入 Historical Lens，再按严格的时间隔离流程复盘。
该相似度只描述历史形态接近程度，不使用后来收益，也不是预测模型。

点击“下载异动研究报告（HTML）”，可以保存一份独立中文报告。报告包含
当日指标、历史分位、行情和换手率来源、官方公告链接、被排除的未来公告
数量以及限制说明。若页面找到历史相似异动，报告还会保留规则相似度、
共同信号、可比维度和 Historical Lens 专属复盘入口，但不会写入后来收益。
点击某个历史案例的“直接复盘”后，网页会自动载入对应公司和历史日期，
无需再次手工选择；随后仍由用户决定是否揭示后来表现。
下载后可离线打开；如果需要 PDF，可在浏览器中选择“打印”并另存为 PDF。
导出只复用页面已经核验的结果，不会再次请求数据，因此不会额外增加免费
服务器的分析内存压力。

“涨停候选”不是交易所最终认定。系统会保留新股上市初期、重新上市、
退市整理首日、价格最小变动单位等例外提示。普通换手率也不会被冒充为
“有效换手率”；后者需要可核验的时点自由流通股本作为分母，当前缺少该
证据时会明确显示“暂不计算”。

涨跌幅参考规则截至 2026 年 7 月 30 日，依据
[上交所 2026 年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)、
[深交所主板规则说明](https://investor.szse.cn/knowledge/qa/t20230306_599093.html)和
[北交所 2026 年交易规则](https://www.bse.cn/jygl_list/200028217.html)。

这些数据只描述已经发生的历史表现，不能单独证明公司价值，也不能预测未来价格。

### 10. Historical Lens

选择一个历史研究截止日后，系统会：

- 为贵州茅台提供三个已经人工核验、带官方原文链接的重要日期；
- 继续允许用户自由选择其他历史日期；
- 接收下载报告的安全复盘链接，并只在首次打开时自动带入公司和日期；
- 使用该日期之前最近一个交易日作为有效行情日；
- 用截止日前的数据重新计算收益率、波动率和最大回撤；
- 只显示发布日期不晚于截止日的官方公告；
- 自动整理所选日期最近七个自然日的“异动—公告证据链”；
- 同时记录用户选择日期和实际采用交易日；
- 默认隐藏后来行情，直到用户点击“揭示后来 1、3、6 个月的市场表现”。

历史页面默认使用不复权价格，避免今天的复权因子把后来发生的分红、送转等信息
带回过去。后来结果只用于复盘，不能证明某一公告造成了价格变化。

### 11. 全市场按需财务快照 Agent

选择公司后点击“生成最新年报财务快照”。系统会依次核验公司身份、寻找最近
550 天内最新完整年度报告、临时下载 PDF、勾稽利润表/资产负债表/现金流量表，
并统一校验金额单位。

只有三张报表、金额单位和五项核心数值全部通过，页面才会显示换算为人民币元
的营业收入、净利润、经营现金流、总资产和总负债，并计算比较栏变化、净利率、
现金利润比和资产负债率。每项数值都保留报表名称和 PDF 页码，也可以下载 HTML
核验底稿。

本功能不会预先下载全部上市公司资料。每次只处理用户主动选择的一家公司和一份
报告，文件上限为 45 MB；解析结束后释放 PDF 与全文，只在当前会话保留小型
结构化结果。如果分母为零、版式不支持或单位不一致，系统显示“待核验”，不会
用 0 或 AI 猜测补齐。自动检查通过仍然只是候选数据，必须打开官方原文人工复核，
也不会自动进入已核验多年趋势目录。

### 12. 年报与证据

选择公司后，页面会尝试找到最新完整年度报告；同一报告年度同时存在中文原版
和英文版时，优先使用中文原版。点击“自动载入并分析”后，服务器会从受信任
的巨潮资讯地址临时读取 PDF，并进入原有证据分析流程。

自动载入有三层保护：

- 只接受巨潮资讯等允许的官方披露域名；
- 限制文件大小；
- 检查文件是否具有有效 PDF 标识。

如果官方站点限流、报告过大或链接结构发生变化，请打开官方原文下载 PDF，再使用手工上传入口。

### 13. 已核验公司扩展 Agent

该页面用于扩大“已核验深度案例层”。输入公司后，先点击“发现最近三份完整
年报”。系统只读取官方目录，不会在这一步下载大量 PDF。随后一次选择并解析
一份报告，以保护 Render 免费服务器的内存。

每份报告会显示合并利润表、合并资产负债表和合并现金流量表是否通过，保留
营业收入、净利润、经营现金流、总资产、总负债及其 PDF 页码。相邻年度都完成后，
系统还会比较后续报告的上年列和早期报告的首次披露值，把不同之处标为可能的
追溯调整或口径变化线索。

点击“下载公司接入候选包（JSON）”可以保存进度。候选包始终注明没有写入正式
目录且需要人工批准。即使自动检查全部通过，也必须人工核对合并口径、金额单位、
页码和重述说明后，才能加入财务趋势实验室。PDF 只在本次请求中临时处理，单份
上限 32 MB，服务器不长期保存 PDF 全文。第一版主要适合普通非金融企业；银行、
保险和证券公司的特殊报表结构需要另行适配。遇到同时展示合并与母公司数据的
四列表格时，系统只读取前两列合并数据，不会把后两列母公司数据混入结果。

### 14. 财务趋势实验室

当前提供六个逐年人工核验案例：贵州茅台、五粮液和泸州老窖 2022—2025 年，
宁德时代和比亚迪 2022—2024 年，美的集团 2023—2025 年。页面展示营业收入、
归母净利润、经营现金流、净利率和负债占总资产的变化。系统会计算首末年度之间的复合年变化率，并比较最新年度
“收入—利润”“利润—经营现金”的方向是否一致。

页面不会把方向一致解释为利好，也不会把方向不一致直接解释为风险；它只是提示
用户继续核查营运资本、税费、季节性和一次性项目。每个年度都保留官方年报链接、
公开日期、主要数据页码和合并资产负债表页码。若后来年报发生追溯调整，调整后的
数字只从其公开日期起生效。

宁德时代不同年度报告使用过“万元”和“千元”两种披露单位，系统在数据文件中
统一换算为人民币元后再计算，并保留原报告页码。其他公司在完成同等级逐年核验
前不会显示未经验证的多年聚合数据。该模块不需要付费 API，也不会预测未来业绩
或股价。

比亚迪年报的主要指标以元披露，而合并资产负债表以千元披露；系统同样统一换算
为元。2024 年报告把比较期标注为经重述，但本页面使用的五项核心字段没有发生
数值变化，因此不会为了增加版本数量而重复记录相同数据。

五粮液 2023 年报追溯调整了 2022 年数据，系统会按报告公开日期在首次披露版和
调整版之间切换。2025 年报披露的部分收入确认核算调整和季度数据差异也保留在口径
备注中，便于追溯。

泸州老窖已核验 2022—2025 年四份完整年度报告。四份报告均明确无需追溯调整或
重述以前年度会计数据；系统记录主要财务指标页、合并负债页和官方 PDF 链接。

页面现在还会显示“标准化接入检查”状态。已核验公司统一登记在接入清单中；系统
自动检查股票代码与交易所是否一致、年度是否连续、数据文件是否位于受控目录、
官方链接和页码是否存在、金额是否有效，以及会计版本是否重复。新公司全部通过后
会自动进入选择列表，不再需要逐个修改页面代码。自动检查不能代替人工阅读年报，
但能避免漏填年度、写错单位或引用错误文件后直接上线。

### 15. 财务异常解释 Agent

当已核验趋势中出现“收入和归母净利润增长，但经营现金流下降”时，
该页面不会直接让 AI 猜测原因。第一个受控案例为美的集团 2025 年：
营业收入同比增长约 12.1%，归母净利润同比增长约 14.0%，经营现金流
同比下降约 11.8%。

系统使用美的集团 2025 年报第 233 页的“现金流量表补充资料”，将14个
调节项统一从千元换算为人民币元。两个年度的逐项加总分别与已核验经营
现金流一致，各项同比变化的合计也与经营现金流减少 71.66 亿元一致。

已证实的最大负向桥接项是“经营性应付项目的增加”，它对经营现金流的
正向调节贡献同比少了约 390.29 亿元。存货、经营性应收项目和合并净利润的变化
提供了主要正向抵消。这些是算术桥接，不自动证明供应商付款节奏、并表范围或
结算政策等业务因果。因此页面把这些内容列在“待进一步核查”中。

趋势信号使用归母净利润，而年报现金流调节表以合并净利润起算，两者口径不同，
页面会明确提示。该功能不需要付费 API，可下载带官方链接、页码和证据指纹的
中文 HTML 报告，不预测未来业绩，不构成投资建议。

### 16. 跨公司横向比较

页面默认选择全部已核验公司，并自动寻找它们最近的共同财务年度。当前贵州茅台、
五粮液、泸州老窖和美的集团已核验至 2025 年，宁德时代和比亚迪已核验至 2024 年，
因此六家公司一起比较时默认采用共同覆盖的 2024 年，不会把不同年度直接并排。

指标表和图表分别展示营业收入、归母净利润、经营现金流、同比变化、归母净利率、
现金利润比和负债占总资产。所有金额统一换算为人民币亿元，所有比例由 Python
确定性计算。页面同时保留每家公司所用年报的公开日期、主要数据页码、合并负债
页码和官方 PDF 链接。

页面还会读取独立的行业证据目录，显示年报披露行业、研究同行组、来源页码和证据
等级。当前六家公司覆盖白酒制造、动力与储能锂离子电池、新能源汽车整车
（多元化业务）、智能家居与家用电器（多元化业务）四个研究组，因此全选时仍是跨行业比较。白酒组已有贵州茅台、
五粮液和泸州老窖三家核验公司，选择其中至少两家时会显示“同行组候选”。

只有至少两家已核验公司具有相同研究标签和共同财务年度时，页面才会显示“同行组
候选”；此后仍需检查业务分部和会计口径。“高于样本中位数”只说明当前样本中的
相对位置，不能解释为公司更好、风险更低或值得买入。页面不会生成综合优劣分数，
也不包含估值或目标价。

当选择贵州茅台、五粮液、泸州老窖中的至少两家且共同年度为 2023—2025 年时，
页面会进一步显示“白酒经营质量透视”。该面板使用合并年报中的营业成本、存货
和合同负债，加上已经核验的收入、总资产、经营现金和归母净利润，计算合并毛利率、
存货同比、存货占资产、合同负债同比、合同负债占收入和经营现金/利润。页面同时
显示 2023—2025 年合并毛利率、存货/总资产、合同负债/收入的三年趋势；点击页码
说明可以检查九组公司年度数据所在的年报页。

请注意：白酒存货包含需要长期储存的基酒，增加不等于积压；合同负债只是年末
客户预付款的时点数，不是订单或未来收入；合并毛利率也不等于旗舰单品毛利率。
系统因此只分别展示指标，不计算综合经营质量分数，也不输出买卖建议。

## 四、动态墙是否需要每天人工更新

不需要每天手工更新。用户进入公司研究页面时，系统会按需读取公开公告，并缓存一小时：

- 一小时内重复查看同一家公司，会优先使用缓存，减少对公开数据源的压力；
- 缓存到期后再次访问，系统会重新请求最新公告；
- 公告请求设置单次超时、有限并发和安全页数上限；年报页面只查询年报类别，
  避免读取无关公告；
- 当前版本不设置全天候后台定时任务，因此不会产生长期运行的额外服务器成本；
- 未来有稳定用户量后，再评估定时更新和推送。

这是一种适合自费早期产品的做法：用户看到的是自动更新，开发者不需要每天人工维护。

## 五、哪些功能需要付费 API

下列功能首版不需要 OpenAI 付费 API：

- 公司名称和股票代码检索；
- 官方公告动态墙；
- K 线与市场指标；
- 官方年报定位和临时载入；
- 已核验公司扩展 Agent 的候选任务、逐份报表核验和 JSON 导出；
- PDF 文字提取；
- Python 财务计算；
- 贵州茅台、五粮液、泸州老窖、宁德时代、比亚迪和美的集团已核验案例的财务趋势实验室；
- 美的集团 2025 年已核验现金流桥接的财务异常解释 Agent；
- 已核验公司的共同年度横向比较；
- 本地证据检索、Skeptic 和 Verifier。

只有可选的自然语言 LLM 综合需要单独的 OpenAI API 额度。ChatGPT 订阅与 OpenAI API 账单是两套系统。

## 六、年度报告分析步骤

### 第一步：取得报告

优先点击“自动载入并分析”。如果失败，点击“查看官方原文”，下载公开年度报告后手工上传。不要上传个人银行资料、客户资料或其他机密文件。

### 第二步：检查自动提取结果

系统会先显示“三张报表自动核验”面板，再显示 PDF 文本预览、原始页码和
能够识别的报表数据。中国上市公司的报表经常跨页，系统会在有限的相邻页内
拼接同一张报表，并显示完整页码范围。关键报表关系会进行勾稽核对；报表结构
不符合预期时，系统应停止并提示，而不是猜测数字。

当前已支持经验证的 Tesco 英文六列表结构，以及普通中国 A 股“合并利润
表”中的营业收入、归属于母公司股东的净利润、本期/上期金额和人民币单位。
如果归母净利润存在，系统会优先使用该行；缺少收入或利润时停止提取，不用
其他相似栏目猜测。

普通中国 A 股“合并资产负债表”现已支持流动资产、非流动资产、资产总计、
流动负债、非流动负债、负债合计和所有者权益合计。系统同时执行三类勾稽：
流动与非流动资产之和等于资产总计、流动与非流动负债之和等于负债合计，
以及资产总计等于负债合计加所有者权益合计。任一关系不成立时停止提取。

普通中国 A 股“合并现金流量表”现已支持经营、投资和筹资活动现金流量净额、
汇率影响、现金及现金等价物净增加额、期初余额和期末余额。中国报表的净增加额
通常已经包含汇率影响，因此系统使用中国报表专用公式，避免重复加入汇率影响。

贵州茅台 2025 年度报告已用于真实结构验证：合并资产负债表覆盖 PDF 第
56–59 页、合并利润表覆盖第 61–62 页、合并现金流量表覆盖第 64–66 页。
页面所示页码来自 PDF 文件本身，方便打开官方原文逐项复核。

### 第三步：向年报提问

可以输入：

- 为什么经营现金流增加？
- 本期营业收入增长率是多少？
- 总负债是多少？
- 管理层对流动性风险作出了什么说明？

### 第四步：阅读分析链条

回答区域依次展示 Agent 路由、Python 计算、动态升级、多 Agent 轨迹、证据结论、Skeptic 质疑、Verifier 审计和 PDF 页码。

中文问题默认使用透明的中文关键词和财务概念检索。当前免费服务器会完全关闭
本地英文语义模型，并且只暂存最近一份年报及其检索文本，避免处理长年报时超过
内存上限。核心的取数、核验、证据检索和页码追溯不受影响。可选 LLM 综合默认
关闭；只有用户主动打开时才会使用 OpenAI API 额度。

检索器同时理解中文报表行名和英文报表术语。例如输入“营业收入是多少”“资产
负债率是多少”或“经营现金流为什么下降”，系统会直接在中文年报中寻找相应报表
行或说明文字，并保留原始 PDF 页码。

### 第五步：下载审计记录

点击“下载 Agent 审计记录（JSON）”，保存本次分析采用的路由、证据、页码、质疑和验证结果。

## 七、人民币财务指标演示

在手工财务分析工具中选择 `CNY (¥ 人民币)`，然后输入同一口径、同一报告期的金额。

- 净利润率 = 净利润 ÷ 营业收入
- 营业收入增长率 =（本期收入 − 上期收入）÷ 上期收入
- 流动比率 = 流动资产 ÷ 流动负债
- 资产负债率 = 总负债 ÷ 总资产

货币选择只改变金额的业务含义，不改变公式。

## 九、严谨性设计

- 财务比率和市场指标由 Python 计算，LLM 不负责重新计算关键数字。
- K 线数据先检查日期、数值类型和开高低收关系。
- Historical Lens 按公开发布日期过滤证据，报告期不能代替发布日期。
- 当时快照与后来结果由不同 Python 函数生成，防止未来数据混入。
- 异动—公告证据链排除未来公告，并明确禁止把时间接近当作因果结论。
- 公告只展示允许的官方域名，并保留原始链接。
- 年报自动载入前检查官方来源、文件大小和 PDF 标识。
- 每条年报证据尽量保留 PDF 页码。
- 数据不足不显示为 0，而是明确标记“数据不足”。
- Skeptic 主动寻找限制和反方证据。
- Verifier 检查证据门槛、引用页码和输出一致性。
- API 密钥保存在服务器环境变量中，不写入代码仓库。

## 十、已知限制

- 公开数据源可能限流、暂时不可访问或改变字段。
- 当前自动年报定位主要依赖巨潮资讯；其他交易所链接会保留原文但不一定能自动载入。
- 中国上市公司报表版式和行业差异较大，银行、保险和普通工业企业需要分别适配。
- 现有确定性提取器已支持普通中国 A 股合并利润表、常见合并资产负债表及
  合并现金流量表；银行、保险等特殊行业版式仍属于扩展阶段。
- 扫描图片型 PDF 可能需要 OCR。
- 前复权行情来自公开行情适配器，不等于交易所原始逐笔数据。
- 媒体新闻尚未加入首版，因为来源质量、版权和“利好/利空”误判风险高于官方公告。
- Historical Lens 可计算任意可取得行情日期的市场快照，并已为贵州茅台
  加入三个带官方来源的重要时点及确定性的异动—公告证据链；扩展到五个
  人工核验时点仍在建设中。

## 十一、常见问题

### 1. 页面提示公开数据源不可用怎么办？

稍后刷新。官方公告和行情故障彼此隔离；年报手工上传和已有本地计算仍可使用。

### 2. 为什么输入陌生代码时显示“待核验公司”？

实时公司目录暂时不可用时，系统只能根据代码规则判断交易所。名称未核验前不要据此形成结论，待数据源恢复后重新搜索。

### 3. 为什么自动载入年报失败？

可能是官方站点限流、文件过大或链接结构变化。打开官方原文下载 PDF，再手工上传即可。

### 4. 为什么系统没有给出利好或利空？

公告标题不足以可靠判断对公司价值的影响。系统只标记阅读优先级，避免伪装成确定结论。

### 5. 为什么分母为零时不计算？

净利润率、增长率、流动比率和资产负债率都涉及除法。分母为零时没有可解释的财务意义，因此系统会停止并显示原因。

## 十二、面试总结话术

“这是我独立设计和研发的中国上市公司自主研究 Agent。用户输入公司名称或股票代码后，系统按需连接官方公告、历史行情和年度报告。Python 负责确定性计算，官方链接和 PDF 页码负责追溯，多 Agent 工作流负责路由、质疑和验证。它的目标不是预测涨跌，而是提高自主研究的效率与可靠性。”
