# 多年公开财务覆盖 · 2026-09-21

本记录描述本地新增代码，不代表线上已更新。本次未提交、切换分支或部署，原有未提交工作保留。

## 用户可以做什么

1. 在财务趋势中搜索A股公司，点击“获取或刷新当前公司年度财务”。最多显示六个完整年度的收入、归母利润、经营现金流及资产负债金额。
2. 看到同比、金额变化与利润/现金不同向的待核验线索；不能把线索读成业务原因或投资建议。
3. 在横向比较中选择“任意A股公开数据（待核验）”，输入2至5个代码，按共同年度比较规模。没有共同年度时停止，不拼接不同年份，不默认认定同业或排名。
4. 一键综合研究在缺少已核验历史和财务快照时按需取数；现有已核验资料优先。已有快照时仍可去趋势页获取多年公开数据。
5. 下载公开财务HTML及来源字段JSON；比较页可下载CSV。综合研究HTML/JSON也保留候选来源和取数时间。
6. 将候选结果加入当前公司的研究案件，继续去官方年报核验。综合研究自动写回时同时携带紧凑公开财务产物。

## 来源、边界和计算

- 来源：东方财富 `RPT_F10_FINANCE_MAINFINADATA`，仅年报，人民币口径，当前源版本。固定HTTPS地址，单次请求最多六行、512KB；连接/读取超时为5/15秒，流式读取检查25秒时限，不自动重试。时限是应用检查，不能保证操作系统层面严格25秒中断。
- 每个年度校验公司代码、交易所、报告期、公告日期、版本日期与币种；重复年度、未来披露、非有限数值和错误公司拒绝进入结果。
- 营业收入 `OPERATE_INCOME_PK` 与营业总收入 `TOTALOPERATEREVE` 分列，缺失不互相替代；净利润采用归母口径。
- 同比只比较相邻同报表类型年度，且基期大于零。零/负基期保留金额变化，增长率留空。年度缺口不跨越计算同比。
- 资产勾稽容差为相对1e-5或绝对1元；不通过时暂停负债率。勾稽通过不代表审计或真实性认证。
- 银行、保险、证券模板不运行通用利润/现金规则。行业百分比是数据源披露值，可能为监管/母公司口径，未自行认证。源的“通用”模板也可能包含金融控股公司，因此仍提示人工确认适用性。
- 每个结果包含取数时间、源字段、公告/更新日期、确定性计算、缺口、SHA-256指纹。指纹只识别数据包，不认证来源真实性。
- 当前版本可能含历史重述，不能用于 Historical Lens 的过去信息集。原有六家公司逐页核验目录没有扩充或被覆盖。
- 页面默认不下载全市场数据。点击取数后按公司缓存一小时，跨UTC日期失效；当前会话最多保留五家公司。刷新失败清除该公司的旧页面结果，避免伪装刷新成功。
- 研究案件仅加入 `public_unverified` 分析产物，保存最近两年来源字段/金额及完整结果指纹；不加入已确认事实，不代替原始报告页码。完整六年数据通过JSON导出保留。

## 零与负基期的变化率（同日后续）

原按需年报快照直接使用(本期-上期)/上期，亏损从100缩小到50会显示-50%，
容易误读。新生成的快照仅在比较基期为正数时显示百分比；零或负基期保留原始
两期金额，新增change_rate_note说明“不展示百分比变化”的原因。缺失或未通过
检查的金额仍不补零；非有限计算结果也不展示。页面及HTML导出同步显示说明。

本轮不改动比率公式或已保存的历史快照，不迁移旧案件。旧快照需重新生成才能
获得新规则。正基期转亏（例如100到-50）的-150%变化仍可展示，不把负结果隐藏。

新增5项测试：亏损收窄、扭亏、负现金流扩大、零基期、正基期转亏，验证两期金额

### 宁德时代2024：为什么可以保留一千元差异

这是保守的显示舍入容差，不是重要性阈值，也没有将差异强行抹平。金额保持年报披露原值。元单位、缺少单位、外币或带小数披露继续使用原有0.5个原始单位规则；超过1个单位的差异仍拒绝。银行已有专用规则不受此改动影响。

### 新模板做了什么

新增 `src/securities_statement_extractor.py`，只支持明确的“合并及母公司”四列版式。每页核对“本集团、本公司”、附注五、当前/上年/当前/上年四列及人民币元单位；同表续页最多三页，拒绝页码跳号、列序错误、混入另一报表和超长续页。

集团和母公司两年数据均校验：收入组成、利息净收入、支出组成、营业利润、税前和税后利润、归母与少数股东利润；资产=负债+权益、归母与少数股东权益；经营/投资/筹资现金流入加带符号流出、三类现金流加汇率变动、期初到期末现金。母公司列少数股东利润和权益须为0。以Decimal计算，勾稽绝对容差0.01元，不用百分比容差，不将支出擅自取绝对值。

只输出集团前两列。金额来源分别保留PDF189—191页资产负债表、192—194页利润表、195—197页现金流量表。标题、来源和两源对照保留“营业总收入”的证券口径；公开源对应 `total_operating_revenue` 字段，缺失时不退回另一个收入字段。普通公司比例在候选、复核底稿和案件端均保持停算。

### 收入差异为什么不能直接覆盖

公开源当前保存的2024收入为33,519,165,071.03元，更新时间2026-03-31，与原年报相差7,947,202,322.77元。后续核查[华泰证券2025年年度报告](https://static.cninfo.com.cn/finalpage/2026-03-31/1225050753.PDF)：

- PDF第24页明确并列2024收入调整前41,466,367,393.80元、调整后33,519,165,071.03元。
- PDF第238页说明标准仓单交易会计政策变更及追溯调整：投资收益调减86,959,798.95元，其他业务收入调减7,860,242,523.82元，合计收入调减7,947,202,322.77元；其他业务成本相应调整。
- 同页说明集团利润总额、净利润和现金流量表等不受这次变更影响，与本轮其余四项金额相符的结果一致。

原披露值和后续重述值都保留；差异回执仍为 `amount_difference`，没有改成“完全一致”，没有改写2024快照。这次归因来自本次对官方文件的核查，尚未实现对所有公司的自动重述归因，也没有把公开源当前版本用于历史时点回测。
