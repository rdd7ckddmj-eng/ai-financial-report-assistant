# 白酒经营质量透视产品规格

## 1. 产品目的

该面板在通用横向比较之上增加白酒行业常用的经营结构指标，回答“利润表、
存货、客户预付款和经营现金能否形成一条可追溯证据链”。它不预测需求，不把
存货增加直接解释为积压，也不把合同负债增加直接解释为利好。

面板只在用户选择贵州茅台、五粮液、泸州老窖中的至少两家，并使用共同的
2023—2025 财务年度时启用。除所选年度横向比较外，页面还连接三个已核验年度，
展示同一指标的历史变化。2022 年只作为 2023 年同比基数，不单独生成质量面板。

## 3. Python 确定性计算

- 合并毛利率 =（营业收入 − 营业成本）÷ 营业收入；
- 存货占总资产 = 年末存货 ÷ 年末总资产；
- 存货同比 = 本年末存货 ÷ 上年末存货 − 1；
- 合同负债占收入 = 年末合同负债 ÷ 当年营业收入；
- 合同负债同比 = 本年末合同负债 ÷ 上年末合同负债 − 1；
- 经营现金/归母净利润 = 经营活动现金流量净额 ÷ 归母净利润。

页面不对这些指标加权，也不生成综合经营质量分数。

## 4. 解释边界

- 合并毛利率包含各公司的全部合并营业收入和营业成本，不等同于旗舰单品毛利率；
- 白酒存货包含需要较长储存和陈化的基酒，存货增加不自动等于滞销；
- 存货占资产受到现金、金融资产、财务公司等资产结构影响；
- 合同负债是资产负债表日的客户预付款余额，不等同于订单、全年动销或未来收入；
- 经营现金/利润受税费、经销商付款节奏、收入确认和营运资金影响；
- 五粮液 2025 年报披露部分业务收入确认核算调整，比较时必须保留该口径提示；
- 本面板不提供估值、盈利预测、目标价或买卖建议。

## 5. 自费部署边界

当前数据量只有九行，由项目内的受控 CSV 提供，不需要付费 API、数据库、后台
爬虫或额外常驻内存。未来扩展到其他年度时，仍必须逐份核对相同报表项目和页码，
不能用搜索摘要或第三方聚合数字直接填充。
