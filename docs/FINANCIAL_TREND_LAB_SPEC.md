# 财务趋势实验室产品规格

## 1. 一句话定义

财务趋势实验室把同一家公司的多年完整年度报告放在统一、可追溯的时间轴上，
用 Python 比较营业收入、归母净利润、经营现金流、净利率和负债结构变化，
同时保留每个数字对应的报告版本、公开日期、官方链接和 PDF 页码。

它回答的是：

> 已经公开并逐项核验的多年年报数字，呈现了怎样的经营与财务结构变化？

它不回答估值高低、未来业绩或股票买卖问题。

## 2. 当前核验范围

当前开放两个逐年人工核验案例：

- 贵州茅台 `600519.SH`：2022—2025 年度；
- 宁德时代 `300750.SZ`：2022—2024 年度。

这不是因为产品只能分析两家公司，而是因为多年趋势要求逐年完成：

- 完整年度报告识别；
- 合并口径确认；
- 金额单位和正负号复核；
- 主要数据与资产负债表页码记录；
- 后续追溯调整版本识别；
- 官方链接和公开日期验证。

其他公司仍可使用公司研究、行情、公告和单份年报分析，但在完成同等级核验前，
页面不会用未经验证的聚合数据冒充多年审计序列。

宁德时代 2022—2023 年报主要数据以万元披露，2024 年以千元披露；数据文件
统一换算为人民币元后再计算。换算过程、官方报告日期、主要数据页和合并负债页
均保留在源代码控制中。

## 3. 确定性指标

页面使用 Python 计算：

1. 营业收入、归母净利润和经营现金流净额的年度同比；
2. 首末完整年度之间的复合年变化率；
3. 归母净利率：归母净利润 ÷ 营业收入；
4. 经营现金 / 归母净利润；
5. 负债占总资产：总负债 ÷ 总资产；
6. 上述比率相对上一已核验年度的变化。

复合年变化率只有在首末值均为正且年度跨度大于零时才计算。一个年度的数据
不能产生跨年变化率；缺失值不会用零填补。

## 4. 结构观察规则

页面只比较最新年度各指标的方向：

- 收入与利润同向或方向不一致；
- 利润与经营现金同向或方向不一致；
- 净利率、现金利润比和负债比例相对上一年度的变化；
- 当前序列是否包含追溯调整后的报告版本。

“同向”“方向不一致”只用于提示用户进一步阅读年报，不代表财务质量评分。
经营现金与利润方向不一致可能来自营运资本、税费、预收款、季节性或一次性项目，
页面不会自动归因。

## 5. 报告版本与时间规则

每条记录同时保存财务期间、报告年度和公开日期。若后续年度报告对早期数字
进行追溯调整：

- 调整公开前的历史快照仍使用原始版本；
- 调整公开后才切换到调整版本；
- 页面标明“首次披露”“本期披露”或“追溯调整后”；
- 官方年报链接和证据页码始终保留。

因此该模块与 Historical Lens 共用同一套 Point-in-Time Evidence Engine，
不会把后来才公开的会计信息泄漏到更早时点。

## 6. 页面输出

页面展示：

- 已核验年度范围；
- 三项复合年变化率；
- 最新年度收入—利润和利润—现金结构关系；
- 最新年度金额、同比和财务质量比率；
- 多年金额趋势图；
- 逐年度报告版本、公开日期、页码和官方链接；
- 时间隔离审计和使用限制。

## 7. 安全边界

- 不把复合年变化率外推为预测；
- 不把高净利率、现金利润比或低负债比例直接解释为“好公司”；
- 不使用 AI 补齐缺失的财务数字；
- 不把追溯调整后的数字提前放入历史快照；
- 不提供买入、卖出或持有建议。

该功能使用仓库内的小型已核验数据文件，不需要付费 API、后台定时任务、
数据库或 Render 持久磁盘。
