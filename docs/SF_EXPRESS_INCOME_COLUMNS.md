两页均明确列示 `2025年度／2024年度／2025年度／2024年度`，对应 `合并／合并／公司／公司`，单位人民币千元。归母净利润为 **11,117,216／10,170,427／不适用／不适用**；公司栏不提供这一归属分类，不能补零、借用公司净利润，或改取合并净利润 **11,684,811／10,218,845**。

此前收入 **308,226,647／284,420,059** 已可读取；归母行无法提供四个数字，使收入和利润的整组提取返回缺失。新增隔离路径只在合并及公司四列表中出现“不适用”时启用，要求：

- 这两页各有一个完整列头，均符合上述四年、四角色顺序；整块首表或续表表头缺失也拒绝，不能借另一页表头判断。续页年度一致，单位完整且一致。
- 收入与归母各有唯一行，收入具有四个显式数值单元格；收入公司列原件横线按既有规则为零。
- 归母恰有前两列金额、后两列原文“不适用”，不接受斜线、未知标记、错位、少一列或额外列。
- 原件收入行止于“减：营业成本”、归母行止于“少数股东损益”；之间未知文字、损坏金额或额外附注不能被跳过。母公司独立表、缺页、重复页、错误续页头均不提供替代值。

输出仍为合并收入和归母净利润，保留人民币千元单位及第159–160页范围，不改变输出接口。生产代码按版式与行标签判断，不按股票代码或公司名称匹配。该路径只读取金额；所得税带符号惯例、公司归属关系不适用的处理及三表归一化状态由各自核对模块负责，本专项不以算平为理由选择税费方向。

## 所得税符号和核对范围

同一完整原件第159页将营业成本、税金及附加、管理费用及合并财务费用列成括号负数，标签“财务（费用）/收入”下的公司收入则为正数。所得税四格为 `(3,233,066) / (3,388,416) / (397) / (11,227)` 千元。本批视觉核查第235页附注四(53)：两期所得税费用分别为正值 **3,233,066 / 3,388,416**，对应主表扣减项，说明主表括号表示带符号费用。附注核查是开发证据，生产解析并未声称自动解析或核对全部附注。

`signed_expense_presentation.py` 只在连续同公司同年度页眉、完整四列、人民币千元、上述唯一相邻费用行及其四个明确单元格都成立时，按费用原符号直接加至利润总额。所得税行必须完整止于物理页末，未知附注或额外金额拒绝。程序不试算两种方向后挑相等者；原负数和格式依据保留在快照、网页和HTML中。

两期合并税前至税后利润、合并归属关系、公司税前至税后利润及输出归母金额分别核对。公司两条归属行均保留 `null` 与原文“不适用”；该公司归属关系明确列为不适用，未计作通过。既有少数股东行斜线兼容不混入此路径，真实空白不得替换为不适用。四列经营分项增强检查仍不支持，不能宣称全利润表或完整财务审计。
