# Company Research Engine 产品规格

## 1. 一句话定义

Company Research Engine 是面向中国上市公司的证据型研究工作台。用户输入公司
名称或股票代码后，系统用统一方法整理官方披露、历史行情、年度报告与可核验的
财务指标，并明确区分事实、计算结果、解释和未知信息。

## 2. 产品定位

本模块回答的是：

> 截至现在，我们对这家公司能够确认什么、依据是什么、还有什么不能确认？

它不是聊天机器人，也不预测短期涨跌。它的竞争力来自统一研究流程、确定性计算、
证据追溯、反方检查和可重复结果。

目标用户：

- 希望快速建立公司研究框架的个人投资者；
- 金融、会计和商业分析学习者；
- 需要展示 AI 与金融结合能力的求职者；
- 需要复核公开资料但不希望依赖黑箱结论的研究者。

非目标：

- 自动给出买入、卖出、目标价或收益承诺；
- 代替持牌投资顾问；
- 使用内幕、客户或其他非公开数据；
- 把媒体传闻当作已经确认的公司事实。

## 3. 核心输出

每次研究必须围绕同一个已核验的公司身份，并输出以下部分：

1. **公司身份**
   - 公司名称、六位代码、交易所和标准代码；
   - 身份是否由实时目录核验。
2. **市场事实**
   - 行情最后日期、价格口径、收盘价、成交量和换手率；
   - 20/60/250 交易日收益率、历史波动率和最大回撤；
   - 所有指标由 Python 计算，缺失值显示“数据不足”。
3. **官方披露**
   - 公告日期、标题、类别、来源和原文链接；
   - “关注程度”表示阅读优先级，不表示利好或利空。
4. **年度报告证据**
   - 报告期、发布日期、文件来源和 PDF 页码；
   - 提取值、单位、比较期间和勾稽检查结果；
   - 自动提取失败时保留手工上传和人工核验状态。
5. **研究结论**
   - 已确认事实；
   - 基于事实的中性解释；
   - 反方证据或限制；
   - 尚不能确认的问题。
6. **审计信息**
   - 数据截止时间、数据源、计算口径、代码版本和验证状态。

## 4. 统一证据等级

| 等级 | 含义 | 示例 |
| --- | --- | --- |
| A | 官方原始披露且保留页码或原文链接 | 年报 PDF 某页、交易所公告 |
| B | 经过字段校验的公开结构化数据 | 日 K 线、成交量、换手率 |
| C | 基于 A/B 级数据的 Python 计算 | 收益率、波动率、财务比率 |
| D | 基于已核验证据的解释 | Agent 总结、Skeptic 质疑 |
| U | 未确认或证据不足 | 数据源中断、口径不明 |

界面不得把 U 级内容显示为 0，也不得把 D 级解释伪装成 A 级事实。

## 5. 数据与 AI 的分工

Python 负责：

- 日期过滤、单位转换和数值计算；
- 行情、公告链接和 PDF 的输入校验；
- 财务报表勾稽关系；
- 证据等级、置信状态和审计记录。

AI 只负责：

- 在已经允许的证据范围内整理解释；
- 比较已核验的事实；
- 寻找矛盾、遗漏和需要补充的证据；
- 用自然语言说明“为什么暂时不能下结论”。

AI 不得重新计算关键数字、补齐缺失数字、猜测公告影响或输出投资建议。

## 6. 状态设计

每项核心信息只能处于以下状态之一：

- `verified`：来源和口径均已核验；
- `calculated`：由已核验输入确定性计算；
- `partial`：证据存在但范围不完整；
- `unavailable`：数据源暂不可用；
- `unverified`：取得数据但尚未完成核验；
- `not_applicable`：该指标不适用于当前公司或行业。

状态必须与数值一起显示。仅显示数字而不显示日期、口径或来源不算完成。

## 7. 首版完成标准

首版 Company Research Engine 在贵州茅台上应能：

- 识别 `贵州茅台 / 600519 / 600519.SH` 为同一研究对象；
- 展示带来源和截止日的 K 线、成交量及透明市场指标；
- 展示官方公告和最新完整年度报告入口；
- 对可提取的年报数字保留 PDF 页码和核验状态；
- 在证据不足时明确停止，而不是生成看似完整的结论；
- 导出可供复查的结构化审计记录；
- 在不启用付费 LLM 时仍保留核心研究功能。

## 8. 暂不进入首版

- 全 A 股财务报表自动适配；
- 实时逐笔行情和盘中交易信号；
- 新闻情绪分数；
- 自动选股排名；
- 目标价、涨跌预测和个性化投资建议；
- 长期保存所有公司的全部 PDF。

这些边界用于保护严谨性，也控制自费阶段的服务器与 API 成本。
