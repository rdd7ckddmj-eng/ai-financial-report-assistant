# 从已测试的官方原件生成快照

财务快照页可以选择本公司测试目录中的具体报告年度与文件版本，再点击“读取这份官方年报”。进入页面和更换选项均不触发下载。没有该公司测试记录时，不显示读取按钮；原有最新披露检索和手工上传入口仍可使用。

目录只提供来源，不提供财务金额或通过资格。每次点击重新下载官方 PDF，检查其 SHA-256 与完整页数，再运行当前提取、单位和金额关系检查。文件被官方链接替换、正文不完整或当前检查失败时，不能沿用目录历史通过结果。失败前清除上一份快照及其复核状态。

所选原件可能是历史版本，也可能是曾未通过的版本；界面和报告明确说明不保证为最新披露。旧失败文件不会因同公司另一份文件成功而变为通过。新增入口不记录五项人工财务确认，不打开底稿导出闸门，也不自动保存研究案件。

## 来源与资源边界

入口只接受经完整验证的本地目录中、本公司对应的精确文件标识。下载器逐跳检查现有官方地址白名单、HTTPS、443 端口、PDF 路径和公网地址；TLS 保留官方主机名证书验证，并连接已检查的地址。拒绝私网/混合 DNS、凭据、控制字符、非 PDF、重定向循环及过多跳转，流式检查文件长度和内容签名。

沿用既有 `SNAPSHOT_PDF_MAX_BYTES`（45 MiB）及 PDF 页数/文字量/串行解析限制，没有提高任何上限。手工上传仍为 32 MiB。下载使用 35 秒 socket/读取循环预算；操作系统 DNS 查询本身不在硬超时控制内。完整 PDF 仅为本次请求临时对象，不保存进会话结果或目录，不启用后台预取。

`src/tested_report_snapshot.py` 实现精确来源选择和重新读取；`tests/test_tested_report_snapshot.py` 检查各类官方 URL 分派、重定向/DNS/TLS、流式大小与 EOF、文件指纹与页数、当前解析失败不得继承旧通过，以及 Streamlit 失败状态清除。下载网络可用性需以部署后的实际点击结果单独核实，单元测试不能替代线上验收。
