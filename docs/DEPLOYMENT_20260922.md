# 2026-09-22 发布构建修复

发布提交 7e18f4b 的 Render 构建运行了测试，结果为 950 passed、5 skipped、1 failed。
失败项 `test_comprehensive_runner_keeps_independent_sources_auditable` 原本声明不访问公网，
但新增的公开财务历史通道未被替换为测试数据。在 Render 上取到了真实数据，覆盖率
成为 0.9，而该缺失证据场景期望 0.8。本地无法取到该数据，因此未暴露问题。

修复将本测试的会话状态隔离，并显式模拟公开财务源不可用；保持原覆盖率断言，
另检查首次调用确实尝试该数据源、已有快照时不再次请求。没有修改业务覆盖率算法，
没有删除测试或绕过 Render 的测试门禁。

修复后本地完整测试：956 passed，5 个既有 SWIG 弃用警告。
构建通过与生产上线是不同状态；实际部署结果以 Render 状态及线上版本标记为准。
