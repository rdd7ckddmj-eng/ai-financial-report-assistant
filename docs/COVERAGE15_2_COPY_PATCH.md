# 第 15.2 批：缺少原文摘录时的提示

第 15.1 批真实线上验收发现，中国国航和水井坊新生成的快照中，缺少原文摘录的指标被误称为“旧快照”。缺少摘录本身不能判断快照生成时间。

本补丁仅调整界面、HTML 报告和研究案件中的五处说明文字，统一描述本项未保留原文摘录，并提示回到官方年报核验。同步调整一个已有测试中的两处文案断言。内部兼容状态、原值、单位、页码、财务计算、三表检查、人工复核和导出门禁均不改变。

第 15.1 批基线已核验上线：164 家公司、180 份精确年报原件，164 份候选、16 份待复核；12 个线上场景中 9 个候选、3 个预期阻断。该范围不代表全 A 股覆盖，也不代表人工核验完成。

补丁验证使用完整 Python 测试、既有真实报告的本地 HTML 渲染，以及部署后重新读取中国国航和水井坊原件的线上检查。线上缺口应保持不变；不通过模拟人工确认解锁底稿。部署、版本和运行状态另留独立回执，不把基线的线上结果称为新提交的执行结果。
