# 自选股异动雷达产品规格

## 1. 一句话定义

自选股异动雷达允许用户一次输入最多五个六位 A 股代码，按需读取最新公开
日线，并用同一套确定性规则比较涨停候选、成交量放大和普通换手率历史位置。

它回答的是：

> 我的少量自选公司中，哪几家在最新可得交易日触发了更多需要复盘的证据？

它不回答“下一只会涨的股票是什么”，也不生成买卖建议。

## 2. 为什么限制为五家公司

当前产品部署在 Render 免费服务器。一次下载并长期保存全市场数千家公司
的历史行情，会增加内存、请求量、数据源限流和持久化压力。因此第一版采用：

- 用户主动输入自选股；
- 每次最多五家公司；
- 逐家公司读取，单家公司失败不影响其他公司；
- 只保存小型雷达结果，不保存完整全市场行情；
- 页面按需扫描，不要求开发者每天手工更新。

该限制是成本和稳定性边界，不是金融筛选结论。

## 3. 三项确定性证据

所有数字由 Python 使用现有公开行情适配器计算：

1. **涨停候选：** 最新日涨幅达到对应板块和风险警示规则的参考阈值；
2. **明显放量：** 最新成交量达到此前 20 个交易日成交量中位数的 2 倍；
3. **普通换手率历史高位：** 最新普通换手率达到此前最多 250 个有效
   交易日的 90% 历史分位。

普通换手率不等于有效换手率。缺少可核验的时点自由流通股本时，不计算
有效换手率，也不把缺失值当作 0。

## 4. 排序规则

页面先按触发证据数量从多到少排序；数量相同时，再依次比较：

1. 是否为涨停候选；
2. 成交量相对前 20 日中位数的倍数；
3. 普通换手率历史分位；
4. 股票代码。

排序只帮助用户安排复盘顺序，不是投资评分、上涨概率或估值结论。

## 5. 页面流程

1. 输入以逗号、空格、分号或顿号分隔的六位股票代码；
2. 自动去重、跳过格式错误内容，并明确提示超过五家的部分；
3. 逐家核验公司身份和公开行情；
4. 展示成功数量、至少触发一项的公司数量和复合异动数量；
5. 展示每家公司四项核心数字、触发证据、数据来源和缺失状态；
6. 一键进入该公司的市场异动 Agent，继续查看历史候选与官方公告证据。

## 6. 失败与安全边界

- 单家公司或单一公开数据源失败时，其他公司继续扫描；
- 页面不使用旧样例、新闻摘要或 AI 猜测填补实时行情；
- 不在源代码中保存密钥；
- 不保存用户证券账户、持仓或个人交易资料；
- 不构成买入、卖出或持有建议。
