# 普通公司直接列示利润表：经营分项增强检查

该检查在原有两期税前利润减所得税、净利润归属和输出归母金额检查之外，新增三条关系：

1. 营业收入减营业成本、税金及附加、销售/管理/研发/财务费用，加其他收益、投资收益、公允价值变动、信用减值、资产减值、资产处置，等于营业利润。
2. 营业利润加营业外收入减营业外支出，等于利润总额。
3. 快照输出营业收入，等于同一合并利润表的营业收入行。

每条关系均计算本期和比较期。费用按原文符号扣减，负财务费用因此产生加项；减值收益/损失按原文符号计入。利息费用、利息收入、联营合营投资收益和摊余成本资产终止确认明细均保留原文，但不重复计入上级金额。

## 支持范围与失败行为

最小范围是两列中文合并利润表中的直接列示“营业收入”版式。现有正式原文 fixture 的比亚迪 2024、京东方 2025、海康威视 2025、迈瑞医疗 2025 均通过新增三条两期关系；原始 PDF 指纹、网址和所用页面均保留在对应 fixture。营业总收入/营业总成本版式、合并及公司四列版式明确未支持这项增强检查。

必须逐行读完整个收入至税前利润窗口，必需科目不得缺失，金额必须两列，未知科目、重复行、顺序改变、额外或损坏数字均不会获得增强检查通过。未识别/缺失证据时保留原有税后与归属检查范围，并明确说明增强检查未完成；不能声称检查了所有经营分项。完整取得的证据若计算不一致，整体利润表状态改为 `mismatch`，候选状态进入 `needs_review`。

未启用 OCR、未扩大单位容差。沿用原检查的原文显示单位容差；原表为人民币元或含小数时为 0.01，只有缩放单位、整张表金额全为整数时允许一个原文单位的舍入差。收入输出与原文行的一致性仍以 0.01 个原文单位检查。

## 输出与消费者

`income_reconciliation.operating_reconciliation` 保存 `status`、`passed`、`checks`、`evidence`、`unit`、`pages`、`tolerance` 和 `note`。完整证据的三条关系同时加入主 `checks`，因此现有 UI 和 HTML 金额关系表直接展示；未支持/证据不足的增强检查不被伪装成通过关系。

每行 `evidence` 保存 `label`、两期 `values`（Decimal 字符串）、原文 `excerpt`、`pages`、`notes`、`coefficient` 和 `role`。系数 0 的子项不是新加项，营业利润和利润总额是校验目标；营业外收支属于第二条关系，不能再次加入第一条关系。主 evidence 同时保留已完成增强检查的证据，便于既有的负号文本处理继续保存原文与派生文本的区别。

测试涵盖四份真实年报、每个必需科目两期错值、缺项/重复/额外数字、未知零值科目、母公司串表、子项重复计数、输出收入不一致、候选阻断以及导出关系保留。

本批还支持中国电建 2025 的中文附注格式“五、（八十）”，仅补充顿号加中文括号附注号的语法。正式 PDF 第 122—123 页 fixture 核对所得税两期金额分别为 4,137,137,002.31 和 3,706,302,910.11 元；损坏括号、重复顿号和带额外金额的附注不会被吞掉。

## 营业收入与营业总收入的边界

同一原件第 122 页营业收入附注与金额黏连为“五、（六十五）645,604,120,331.32 633,865,040,639.72”。新的读取规则只在明确的附注列、有序两年度表头和人民币单位下恢复这两个金额；两期营业总收入 646,237,283,223.32 和 634,732,354,204.98 不得替代它们。

只要合并利润表存在“营业收入”科目，即使金额、附注或标签后缀损坏，也不再退回读取“营业总收入”。额外数值、缺列、未知行、重复科目、反转年度、冲突单位和母公司借值均拒绝恢复。确实只出现营业总收入的既有版式保持旧逻辑，未因这次特定格式修复扩大支持范围。

旧原件还包含锦波生物的中文附注跨行“五(三十/四)”、万华化学和中国核电的独立紧凑附注“七61”。这些原文在同一明确附注和两期表头条件下读取，不把缺失金额补零，也不从“七61645...”猜分附注与金额。编号标题“（四）母公司利润表”先被截断，不能被当成第二个合并营业收入行。针对四份原件的回归固定两期收入、归母金额；历史测试的预期金额不因恢复规则变化而修改。
