# 第16批完整年报扩围与跨页现金流读取

本批新增24家公司2025年完整官方年报，使这些公司可以从网站的已测试官方原件入口生成快照。目录从180份、164家公司扩至204份、188家公司。新增23份通过自动检查、1份保留缺口；累计187份通过、17份有缺口，173家公司至少有一份候选。目录仅对应测试过的具体原件，不代表全部A股或其他年度覆盖。

伟星股份2025年现金流表的汇率影响项目跨越PDF第93、94页，原解析因此无法完成三表检查。现金流读取模块现在仅在合并报表身份、两期表头、单位、连续页码、完整拆分标签及唯一金额对全部成立时恢复该行，并保留两页原文和页码。两期汇率影响金额为-7,876,247.43元、9,827,145.77元。重复标签、缺失或歧义单位、表头缺失、母公司边界、页码不连续和损坏金额均有阻断测试。没有修改计算公式、增加OCR或调整资源上限。

修复后完整重跑204份原件，旧180份完整结果逐项一致；新增38项跨页读取守卫测试及24项目录参数用例。没有把缺数补零，也没有新增人工财务确认。旧16份缺口重新定位到原文：利润归属数字不完整、现金流汇率影响留空、扫描页面及特殊保险排版继续阻断。新增缺口为涪陵榨菜少数股东损益两期空白，五项标准化金额继续待核验。

新增24份共120项本期公开金额对照：114项一致、1项差异、5项不可比。海思科总资产年报原值7,010,507,049.86元，公开源7,000,806,498.37元，年报减公开源9,700,551.49元，保留两个来源及人工复核提示；没有根据差额猜测重述或覆盖任一来源。

验证证据以修复后的完整回执、原件SHA、公开原响应、目录集成后的全量测试及真实线上验收为准。发布状态另见第16批发布清单；本文不以本地结果推定已上线。
