## 解析与拒绝边界

模块 `citic_securities_statement_extractor.py` 提供 `is_citic_annual_report_identity(company, pages, year)` 及 `extract_citic_securities_statements(pages, year)`，模板名 `securities_citic_separate_yuan_v1`。共享入口对代码600030优先调用，专项失败不得回退普通模板。

- 身份同时绑定代码、法定名称、中文简称、前20物理页 A 股上市表及对应年报标题；2024 使用确切分行封面，2025 使用可读年度标题。拒绝摘要、错误公司和年度。
- 两期合并及母公司分别核对三表：2024 合并资产负债163–165、母公司166–168、合并利润169–172、母公司173–175、合并现金180–182、母公司183–185；2025 对应176–178、179–181、182–185、186–188、193–196、197–199。金额仅输出合并表，母公司用于额外独立验证，不能借数。
- 强制主表唯一、连续物理页、当前/比较年度次序、主体、人民币元单位、确切科目和附注、两个金额列、页脚及批准签名区。缺行、额外列、损坏负号、未支持的插入文字或单位冲突一律拒绝。审计意见必须绑定同公司年度及中国准则。2025 要求追溯说明原页。
- 每报告60个两期关系，合计120次 Decimal 金额比较：利润27、资产负债11、现金22；每列容差最多0.01元，原件全部零差。覆盖八项收入、费用合计、营业利润、税前税后、利润归属、持续性分类、其他综合收益组成及归属、资产负债主项/权益、三类现金收支与净额、汇率影响及期初至期末。
- 普通费用、收付款保留原呈列约定。明确的净变动现金行可为负；2024 母公司2023比较期经营现金流入小计为 -372,276,122.03 元，仍按原文流入减流出。不得选择哪个符号使等式算平。
- 所有金额token最长32字符、绝对值不超过1e15元，拒绝超大损坏输入，在 float 输出前检查。这个上限是模板支持边界，不是财务真实性判定。
- “其中”项目不重复计入主项；有明确总项者做包含关系。未声称核验每股收益分母或未完整列出的手续费业务细分和所有附注。年度布局、签字人/批准日期变化需要新增真实证据及测试，不能自动猜测支持。
